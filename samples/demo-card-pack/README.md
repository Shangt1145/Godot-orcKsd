# UI 演示卡包（demo-card-pack）

可直接在游戏内「卡包」页导入的最小示例卡包——导入方式：复制本目录的完整路径，粘贴进「导入卡包…」对话框。

内容：
- `pack.json`：包清单（id `orc.ui.demo`；声明一个自定义词条「检阅」，经数据壳效果绑定到效果库预制体）
- `cards/`：两张单位卡——演示步枪兵（无效果）、演示掷弹兵（部署时抽 1 张牌，引用效果库）
- `effects/`：效果库 `orc.ui.demo.rally`（csx 自包含，零 C# 代码）

启用后：卡牌收藏与卡组构筑会出现「pack:UI 演示卡包」分组下的两张卡；DIY 工坊的词条下拉会出现「检阅」。
