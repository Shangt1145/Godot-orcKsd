# 原版 KARDS 交互式选择调研与本项目设计

调研日期：2026-10-06。目标：为「交互式选择面板」（换牌点选、拖拽打出、指向目标、多选候选）提供原版参照、本项目交互设计与实现映射。

前置阅读：`KARDS_BATTLE_RESEARCH.md`（视觉参照与逐帧证据）、`ENGINE_BRIDGE.md`（桥接与自动应答现状）。

## 结论与证据边界

- 原版对局内操作以**拖拽为第一交互**：单位部署、攻击、指令打出均由"从一处拖向另一处"表达；点击只承担选中、详情与词条浮层，未观察到点击式动作菜单。
- **攻击瞄准**：粗红色填充箭头 + 浅色外轮廓；**瞄准期间非目标整行去饱和（灰化），目标保持彩色**；目标侧出现红色伤害徽章（含 0 值也显示）。录像核验。
- **换牌面板已录像核验**：4 张横排大卡 + "选择要替换的卡牌" + 灰色"确认"按钮；**点选标记为红色 ✕ 印记叠加在卡面**；确认后被换的卡倾斜飞出，横幅"敌方正在选择起手牌"期间补抽飞入手牌。
- 回合横幅为**"< 友方回合 >"**（不是"你的回合"），深色横带 + 橙色字，居中。
- **指向性指令的拖拽打出、部署带指向的自动弹箭头：本局录像未出现实例**，仍为本项目拍板设计（D1），原版证据待补。
- 音频未分析（本次只取画面帧）。

## 2. 原版交互事实

### 2.1 拖拽语言（L1 文字级 + V1 核验）

| 操作 | 原版做法 | V1 时间码 |
|---|---|---|
| 部署单位 | 从手牌拖到落点槽位，悬停时卡面放大跟随 | 04:08–04:13（丁格大侦察车） |
| 攻击 | 拖场上单位指向目标，松手结算 | 04:15–04:19；12:19–12:21；03:58 |
| 指令打出 | 从手牌打出，大卡揭示后在侧边停靠 | 00:58（"观察团"左侧停靠） |
| 反制武装/解除 | 支付费用武装；拖回场中解除并退款（L1） | 未在 V1 出现实例 |

### 2.2 换牌面板（V1 00:05–00:19，已核验）

流程逐段：

1. **VS 画面**（00:05–00:07）：双方牌组卡斜靠 + 昵称 + "对战"字样；先手方名字下出现橙色**"先手"**标记（00:06）。
2. **换牌面板**（00:08.5–00:13.5）：先手 4 张**横排、正立、全信息**大卡；下方深色横条提示**"选择要替换的卡牌"**；其下灰色**"确认"**按钮。背景为已就位的棋盘（双 HQ 可见），不另开全屏遮罩。
3. **点选标记**（00:12.5）：点击要换的卡，卡面上叠加**红色 ✕ 印记**（作废章风格），不移动、不翻转；可再点取消（本段未见取消实例，推断）。
4. **确认**（00:13.5–00:14）：确认后被标记的卡**保持 ✕、倾斜、向右上方飞出**；未标记的原位不动。
5. **等待对手**（00:14–00:16.5）：深色横幅**"敌方正在选择起手牌"**；同时己方补抽的新卡以小扇形从下方飞入，归位到手牌扇形。
6. **开局**（00:17.5–00:18.5）：横幅**"< 友方回合 >"**（深色横带 + 橙色字，居中），第一回合开始。

### 2.3 攻击瞄准视觉（V1 03:58；04:16–04:19；12:19–12:21）

- 箭头：粗红色填充、浅色外轮廓，从攻击者卡面指向目标卡面；有长短两种跨度（前线→支援线的短箭头与跨场长箭头）。
- **非目标灰化**：瞄准期间其余可受击单位整行去饱和，目标保持彩色（04:16.5、12:20.0 清晰可见）。
- **伤害预览徽章**：目标侧出现红色盾形/方形数值；04:19 出现红色 "35"（HQ 剩余血旁），05:34 出现红色 "0" 盾徽（0 伤害也显示）。数值来自引擎，UI 不自算。
- 拖拽过程中（04:15.0）可见被拖卡呈侧立薄片跟随指针。
- 未核验：非法目标悬停反馈、取消条件（右键/拖回）、跟随曲线。

### 2.4 单位选中与词条浮层（V1 01:36–01:42；04:09–04:12）

- 悬停场上/手牌卡：卡面放大 + 左侧**关键词浮层**（如 闪电/稳定/山地/洞察，逐条带图标与释义）。
- **未发现点击式"攻击/移动"动作菜单**：L1 的 "tap it, then drag" 对应"点击选中并放大，随后拖拽"，不是菜单。
- 闪电（blitz）单位部署当回合即被拖去攻击（04:12.5 部署 → 04:15 拖起 → 04:16 箭头），佐证"部署后立刻可拖"的输入开放。

### 2.5 指令与反制的打出反馈（V1 00:58；02:28–02:33；09:32；12:28）

- 打出指令：大卡在**屏幕左侧停靠**展示（00:58 "观察团"，约 1/4 屏高，带词条浮层）。
- **黑色 ⚔（交叉剑）卡背标记**：02:31、09:32.5、12:28 出现在**顶部（对手侧）**，为打出后停靠的盖住牌面标记；02:31 一次发生在己方回合（我方从手牌打出指令后），停靠位置却在顶部 —— **停靠归属与朝向规则未定论**，需专项补证。
- 指令结算后的目标表现未在 V1 中捕捉到明确实例。

### 2.6 回合横幅

- "< 友方回合 >" / "< 敌方回合 >"：深色横带贯穿屏幕中部，橙色字 + 白色尖括号，出现约 1–1.5s（V1 00:18.5、00:32、03:16、05:36、12:16.5 等）。
- 无逐帧精确时长与缓动测量（4s 总览网格限制）。

## 3. 本项目交互设计（含拍板项）

### 3.1 交互总表

| 场景 | 触发 | 交互 | 结束方式 |
|---|---|---|---|
| 起手换牌 | `Phase=Mulligan` | 按 §2.2 复刻：横排大卡 + "选择要替换的卡牌" + "确认"按钮；**红 ✕ 印记**做点选标记 | 提交 `ChooseMulligan(KeepUids)`；随后播"敌方正在选择起手牌"横幅 + 补抽飞入；对手侧只露卡背数量 |
| 单位攻击 | 拖场上单位 → 目标 | 红箭头跟随；**非目标灰化**；目标红徽章伤害预览（引擎提供） | 松手于合法目标 = 攻击；拖回/右键 = 取消 |
| 单位移动 | 拖场上单位 → 相邻合法线 | 浅色移动箭头 + 落点槽位提示 | 同上 |
| **指向性指令** | **从手牌拖出 → 指向场上目标**（D1，V1 未见实例） | 拖起即揭示大卡；进入目标域后变红箭头 + 预览 | 松手于合法目标 = 打出；否则取消回手 |
| 非指向指令 | 从手牌拖到桌面空白 | 打出后大卡左侧停靠（§2.5） | 揭示 → 结算 |
| **部署带指向** | 部署落位动画结束（D1） | **自动弹出箭头**进入瞄准态，无需二次拖拽 | 选中目标后结算；取消后单位保持已部署 |
| 反制 | 从手牌拖到己方支援线区 = 武装 | 沿用 Stage4 演出 | — |
| 多选候选 | `PendingChoices` + `PendingChoiceCaption` | 遮罩 + 候选横排；单选即提交，多选凑满出确认键 | 引擎不允许取消时隐藏取消入口 |

### 3.2 状态机

```text
空闲 ──拖起手牌──▶ 拖拽中 ──┬─落点在支援线──▶ 部署预览 ──松手──▶ 部署演出 ─┬─效果带指向──▶ 瞄准中（自动弹箭头，D1）
                           ├─指向性指令指向目标域──▶ 瞄准中（红箭头+预览）  └─否则──▶ 空闲
                           └─非指向指令落空白──▶ 打出揭示（侧边停靠）
空闲 ──拖起场上单位──▶ 拖拽中 ──┬─指向敌方──▶ 攻击瞄准（非目标灰化+红徽章）
                              └─指向相邻线──▶ 移动（浅色箭头）
任意拖拽/瞄准中 ──松手于非法处/右键──▶ 取消回位
Phase=Mulligan ──▶ 换牌面板，提交前封锁其余输入
PendingChoices 非空 ──▶ 选择面板（遮罩），封锁其余输入
```

### 3.3 合法性与预览（来源均为引擎，UI 不自算）

- 可拖：`UiBattleActions` 与 `GetCommandAvailability` 投影决定；费用不足/不可动拖起后回位并给原因提示。
- 合法目标：`ITargeterBridge.CollectCandidatesAsync` 候选集；合法高亮（原版为"非目标灰化"反向表达）、非法置灰。
- 伤害/致死预览：引擎结算结果；未提供结构化预览前只显示目标高亮，不编造数值。
- 取消语义（扩展定义，原版未核验）：拖回原位、右键、ESC 等效；部署带指向的瞄准可取消，取消后单位保持已部署、指向效果不结算。

### 3.4 选择面板

- 遮罩全屏拦截输入；候选横排大卡，悬停放大看详情（词条浮层沿用现有组件）。
- 单选：点击即提交 `ChooseTarget(uid)`。多选：点选标记（建议沿用换牌的红 ✕/勾记语言），凑满 `Min/Max` 后确认键亮起。
- `PendingChoiceCaption` 显示于面板顶部；隐藏信息边界沿用 `UiSnapshots.Freeze`。

## 4. 引擎映射

| UI 交互 | 引擎侧 | 现状 → 目标 |
|---|---|---|
| 换牌点选 | `Match.BeginMulliganAsync` + `TargetSlotKind.MulliganSelect`（min=0） | 自动"全保留" → 面板点选 `ChooseMulligan(KeepUids)`；提交后**立刻重读 Hand**（补抽静默） |
| 指向性指令打出 | `BeginCommandAsync` 目标槽位 | 自动取首个合法 → 拖拽指定 `ChooseTarget(uid)` |
| 部署带指向 | 部署请求后续目标槽位 | 落位动画结束再弹箭头，等待期间对手侧不得推进 |
| 部署落位 | 前线/支援线槽位 | 已实现（P7 最近空槽回放），保留 |
| 合法性 | `GetCommandAvailability`（纯查询、不产段） | 已投影；补拖拽前灰化/置黑 |
