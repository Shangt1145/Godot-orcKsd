# 原版 KARDS 对战界面与动作特效调研

调研日期：2026-10-05。目标：为对战界面、全部动作和特效重做提供视觉参照、动作清单和验收依据。本轮只增加调研资料，没有修改应用代码。

本文第 5 节保留调研当时的实现差距。后续交付情况见 `BATTLE_STAGE1.md` 和 `BATTLE_STAGE2.md`。

## 结论与证据边界

当前原型与原版的差距涉及整个战斗呈现系统：战场布局、卡牌形态、手牌操作、瞄准反馈、武器演出、受击、死亡与信息提示。只修改已有 Tween 时长或粒子颜色无法完成还原。

- 原版至少需要手牌完整卡、战场紧凑卡、详情/出牌揭示卡、隐藏卡背、HQ 五种呈现形态。战场卡以插画、操作费用、攻防和状态为主，不保留完整规则文本。
- 攻击瞄准使用有浅色轮廓的粗红箭头，并显示伤害和可能死亡的骷髅提示；移动使用不同的箭头反馈。
- 出牌和移动体现实体纸卡的抬起、倾斜、缩放、落位及邻卡重排。攻击包含发射、飞行、命中、数值反馈和残留效果，不能合成一次闪光。
- 烟尘、火焰、碎屑与爆炸具有纹理和层次。单位消失以后，效果仍可能继续。HQ 摧毁有独立的大规模演出。
- 兵种只是默认分类。近期官方补丁修正了 STZ-5 KATYUSHA 的攻击动画及音效；近期实机片段也能看到喷火攻击。因此需要卡牌/武器级覆盖配置。[官方 2026 年 9 月补丁](https://www.kards.com/news/kards-update-september-2026)

**已核验**：官方说明与静态截图；两支 Steam 官方宣传片中的实机画面，整片按 1 fps 定位、重点片段按 8 fps 分解并逐页查看。时间码是视频位置。

**尚未核验**：无剪辑完整桌面对局、连续鼠标操作及完整声音。宣传片存在缩放、转场、字幕与可能的时间编辑；8 fps 的采样间隔为 125 ms，不能据此给出原版精确前摇、射速、缓动曲线或音画同步参数。以下逐帧观察与重做建议分开记录。

## 2. 对战布局和卡牌语言

### 2.1 战场结构

```text
                    对手手牌：重叠卡背
 对手信息/资源     对手支援线：HQ + 单位
 历史记录          前线：双方争夺的公共区域        回合按钮/提示
 我方信息/资源     我方支援线：HQ + 单位           牌堆
                    我方手牌：扇形、重叠、底部裁切
```

HQ 是支援线内的地图卡，带城市名称、国别徽记和防御盾牌。前线为单方控制的公共区域；前线容量与支援线部署容量需要表现明确，但是否合法必须使用引擎给出的状态与可行动列表。[前线](https://support.kards.com/hc/en-us/articles/360026464712-Battlefield-elements-The-Frontline) / [支援线](https://support.kards.com/hc/en-us/articles/360026757171-Battlefield-elements-The-Support-Line)

木桌/战场桌面、旧纸卡、低饱和插画和奶油色字构成主要材质。枪械、弹药等道具留在外围。不同棋盘皮肤不能混为一个固定背景。以下是**战役截图**：右侧任务文字、对话及 `ENEMY` 按钮不应直接当作标准 PvP HUD。

### 2.2 卡牌呈现形态

| 形态 | 观察到的信息/构图 | 重做要求 |
|---|---|---|
| 手牌/揭示 | 完整名称、插画、规则文本、费用；扇形重叠或大卡展示 | 独立完整卡布局；拖动时脱离扇形布局 |
| 战场单位 | 插画占主体；顶端操作费用和国别；底端攻击、兵种、防御；外侧状态图标 | 独立紧凑布局，不能把图鉴整卡直接缩小 |

## 3. 已观察动作的分解

以下时间是**素材时间码**，不是建议实现时长。“R”与“T”对应来源表中的两支视频。

| 动作 | 画面证据 | 可确认的过程 | 尚不能确定 |
|---|---|---|---|
| 攻击瞄准 | R 10.25；R 27.75；T 29.25 | 红色填充箭头、浅色外轮廓；目标伤害提示；致死时出现骷髅；攻击者也可能有致死提示 | 所有非法目标反馈、取消条件、键鼠跟随曲线 |
| 普通地面攻击 | R 10–12；R 28.25–28.50 | 瞄准结束后局部暖光/枪口亮点；目标烟尘、火花；双方数值/死亡结果 | 全部步兵武器射速及声音；是否所有卡牌同样循环 |
| 单位部署 | R 12.625；R 25–25.75；R 40–40.625 | 大卡揭示/悬起，缩小、轻微倾斜后进入支援线；切换为紧凑卡；其他卡让位 | 拖拽取消、非法投放、完整落地音和精确时长 |
| 前线移动 | R 41.875–42.50 | 浅色移动箭头；卡牌抬起上移，进入前线；队列重新排布 | 不同卡种是否有差异；控制权切换完整反馈 |
| 指令揭示 | R 26.375–27.25；R 63–63.375 | 完整大卡展示，随后在屏幕侧边停靠；有倾斜退场样例 | 自己/对手侧边方向规则及展示时长，不能由单个剪辑推断 |
| 受击 | R 11；R 28.50；T 30.625；T 41.75 | 纹理烟尘、火花/碎屑；放大的红盾伤害反馈与卡牌底部数值变化 | 精确结算帧、每种弹头命中素材 |
| 地面单位死亡 | R 12.125；R 63.25–64.25 | 卡面消失，原位置留灰黑烟尘、碎屑；邻卡重排 | 每种单位是否有独立销毁素材、所有退场类别 |
| 飞机被摧毁 | T 31.25–31.875；T 42–43.375 | 卡牌位置出现明亮火球、飞散碎片和烟；卡面消失后火焰仍在 | 战斗机/轰炸机发动攻击的完整演出没有被充分核验 |
| 多单位同时移除 | R 63–64.25；T 46–46.875 | 各目标位置分别留下效果；伤害徽章和残留效果可并存 | 所有群体指令的先后规则与特效差异 |
| 特殊喷火攻击 | R 65–67.25 | 连续橙色火焰连接攻击者与目标；命中/死亡后残火延续 | 具体卡牌与配置、持续时间；不能作为所有坦克默认攻击 |
| HQ 摧毁 | R 66.375–68.25 | 致死瞄准提示 → 命中/伤害徽章 → 火焰扩大 → 大型爆炸与碎片 | 爆炸后胜负界面、音效、操作锁定和完整转场 |

## 4. 全动作覆盖清单

状态：**画面**＝本轮实际分解；**文档**＝语义由官方说明确认，动画仍缺证；**待补**＝完整演出尚未核验；**扩展**＝本项目自定义内容。画面状态只表示有样例，不表示该动作的全部变体已研究完。

| 范围 | 动作/反馈 | 证据状态 | 重做时必须覆盖 |
|---|---|---|---|
| 对局开始 | 棋盘进入、先后手、起手牌 | 待补 | 双方信息、隐藏牌、交互开放时机 |
| 起手 | 换牌标记、确认、换回与补入 | 待补 | 选择/取消、牌堆路径、扇形重新排布 |
| 手牌 | 抽牌、生成牌、加入手牌 | 画面部分 / 待补 | 牌堆来源与生成来源分别表现；不泄露对方牌 |
| 手牌 | 悬停、抬升、放大、详情 | 文档 / 待补 | 层级、遮挡、触控与拖动命中区 |
| 手牌 | 选中、拖动、取消、非法投放 | 文档 / 待补 | 费用不足、区域满、目标无效与回位 |
| 手牌 | 弃牌、爆牌、牌堆空 | 待补 | 来源去向、可见性、各自反馈 |
| 部署 | 揭示、落位、召唤、部署触发 | 画面部分 | 完整卡到紧凑卡转换、落点、队列让位 |
| 移动 | 支援线到前线、控制权与重排 | 画面部分 | 移动箭头、占位反馈、原位和新位 |
| 瞄准 | 攻击/指令目标、预期伤害、预期死亡 | 画面部分 | 目标高亮、双方预览、取消、非法目标 |
| 攻击 | 步兵射击 | 画面部分 | 枪口、曳光、反作用、命中、反击；武器级差异 |
| 攻击 | 坦克炮击 | 待补；喷火变体有画面 | 炮口、弹道、后坐；喷火独立覆盖 |
| 攻击 | 火炮射击 | 待补完整样例 | 炮口/烟、飞行路径、命中，不能沿用未测 Web 参数 |
| 攻击 | 战斗机攻击 | 待补完整样例 | 飞行/扫射是否有独立载体、出入场与命中 |
| 攻击 | 轰炸机攻击 | 待补完整样例 | 投弹/爆炸范围、投射物、单目标/多目标 |
| 攻击 | HQ 受击与反击/无反击 | 画面部分 | 对象级反馈、预览与正确事件结果 |
| 受击 | 小口径、炮弹、爆炸、持续火焰 | 画面部分 | 纹理、受击位移、伤害盾牌，避免完全同质化 |
| 死亡 | 单位、飞机、群体、HQ | 画面部分 | 独立素材、残留、位置快照、卡列重排 |
| 其他退场 | 回手、洗回牌库、放逐、变形 | 待补 | 与死亡分开；跨区域形态切换 |
| 指令 | 打出、揭示、选目标、停靠、退场 | 画面部分 / 文档 | 双方方向、时序、隐藏到公开边界 |
| 反制 | 武装、取消、触发、揭示、结算 | 文档 | 原版武装在手牌内，不能默认变成战场陷阱堆；对方触发前不知内容 |
| 状态 | 攻防增减、治疗、费用变化 | 画面部分 | 盾牌与方形费用标记区分；批量变化 |
| 状态 | 压制、钉住、免疫、守护、行动可用性 | 待补完整动画 | 状态图标、遮罩、解除反馈与语义来源 |
| 选择 | 多选一、检索、生成/发现卡牌 | 待补 | 遮罩、候选排列、选择到手牌、取消规则 |
| 近期扩展 | 天气/Forecast 类选择、延迟入手 | 文档 / 待补 | 选择层与跨回合结果；不推断有全屏天气循环 |
| 回合 | 开始、资源刷新、结束、对手行动、倒计时 | 待补 | 信息变化、按钮状态与可操作时机 |
| 历史/提示 | 历史详情、行动失败、连接/等待 | 静态部分 / 待补 | 反馈位置、信息可见性、不遮挡战场 |
| 结束 | 胜利、失败、认输与结算转场 | HQ 过程画面 / 待补 | 独立结局演出及交互封锁 |
| 音频 | 出牌、移动、各武器、命中、死亡、HQ、回合 | 待补听测 | 素材、触发点、距离/方向、并发混音 |
| 项目扩展 | 舰船、太空兵种等 | 扩展 | 延续原版材质语言，另设设计/验收，不声称原版复刻 |

原版地面/空中单位的五类为步兵、坦克、火炮、战斗机、轰炸机。海军子类型通过指令和反制呈现，因此当前 Cruiser 等自定义单位没有可直接照搬的原版战场攻击样例。[官方玩法](https://www.kards.com/how-to-play) / [官方海军说明](https://www.kards.com/news/naval-warfare-navy-subtype)

## 6. 建议的重做结构与顺序

以下是实现建议，不是对原版内部实现的断言。

1. **先做战场基础**：建立区域坐标、卡牌呈现形态、手牌扇形与交互层；实现瞄准箭头、目标高亮、伤害/致死预览。必须先有真实棋盘，才能校准尺寸与效果范围。
2. **完成实体卡动作**：部署、移动、抬起/落下、队列重排、详情和取消回位。布局拥有最终位置，演出层只控制临时偏移，避免下一动作跳回旧位置。
3. **替换战斗特效管线**：按发射→投射→命中→反馈→销毁组织事件。武器配置先按卡牌 ID 覆盖，再落到兵种默认值；补齐五类原版单位参考后分别制作。准备枪口、曳光、弹体、火焰、烟尘、碎屑、爆炸的分层素材。
4. **完成结果和扩展流程**：单位死亡/HQ、群体事件、指令、反制、状态、选择、回合及音频；自定义兵种另列设计参照。
5. **在真实棋盘验收**：画廊用于单项调参，连续对局用于检查重叠效果、排布变化、时序、隐藏信息与输入中断。

已有 DTO、卡牌 UID、可见性、目标候选与动作片段的消费契约可以保留；演出不替代引擎规则。伤害预览与结算均使用引擎结果。残留特效保存位置快照；大卡揭示和投射物使用不拦截输入的独立层。动画取消/切页后必须落在可信状态。

既有 `shots/gap/travel/recoil`、按防御区分落地时长等参数不能标注为“原版参数”。后续从无剪辑 30/60 fps 录像测量，再记录动作起止、命中帧、数值更新帧和音频触发点；使用区间而非凭宣传片写死毫秒。

### 视觉验收

- 每个动作使用同类场景、同类目标与同一尺寸，对照原版截图/分解图和本项目画面；检查布局、箭头、卡牌姿态、命中位置、烟火材质、数值徽章及残留。
- 逐项覆盖普通/致死/双方死亡/多目标/空目标，HQ 与单位分开；隐藏手牌、反制和选择不能泄露信息。
- 连续执行部署、移动、攻击、死亡及再次操作，检查邻卡重排、粒子位置和输入区域；覆盖取消、打断、切页和减弱动效。
- 自动化检查证明事件消费和状态可靠；视觉与声音还原必须另有画面/听测依据，不能用测试通过代替。

## 7. 下一轮必须补齐的证据

最高优先级：当前桌面版无剪辑完整对局，含鼠标与原声；分别找步兵、坦克、火炮、战斗机、轰炸机的普通攻击，以及喷火/特殊武器变体。随后补起手换牌、抽牌/爆牌、非法投放、指令、反制、选择、天气、回合切换和胜负界面。

每个补充片段记录版本/平台、卡牌名称、时间码、触发前后状态、可见性、前摇/发射/命中/退场及声音。无法辨识的单位不按文件名或外观猜兵种。本次 `air-observed-*` 只是 R 17–21 秒混合战斗的历史文件名，**不能作为飞机攻击已核验的证据**。

首轮已足以确定重做边界及基础视觉方向；全动作的精确时序和声音仍需要上述录像补证。
