# 归档区

这里放**一次性过程记录**：它们的结论已经被后续文档吸收，或者只对当时那一轮工作有意义。
保留是为了可追溯（"当时为什么这么决定"），不是为了拿来当现状依据。

判断标准——满足任一条就进来：

- 记录的是"某一次整理／某一次待命／某一次排查"的动作本身，不是项目知识；
- 结论已被更新的一篇取代，且旧的没有独立信息价值；
- 只在当时的时间窗口内成立（版本号、引擎 commit、目录结构都会变）。

**不进这里**的：原版行为调研（`research/`）、阶段验收（`acceptance/`）、
交接与计划（`planning/`）——哪怕已经过时，它们仍是"某个功能做到哪一步"的证据，
过时归过时，位置不变，由 [索引](../README.md) 标注状态。
