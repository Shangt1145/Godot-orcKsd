# 自定义对战词条系统（开发中）

目标：Godot 负责编辑与表现，OrC-KSD 负责规则、计时、状态、目标选择和结算。不能将词条名称或几个样例硬编码作为完成标准。

## 统一定义

词条程序包含参数默认值、实例状态、规则贡献、事件处理器及主动技能。行为使用通用操作和条件组合；卡牌引用词条并给出参数。每局冻结程序版本；每个词条实例独立存储状态。生成卡可携带独立键值记录，数值快照不依赖源卡继续存在。

规则组合使用显式优先级，同优先级限制优先；不改变引擎内核 moding 的纯替换语义。候选、费用和执行复验必须保持同源。特殊效果发起的攻击具有明确来源，仍走攻击触发器和真实交战；不会直接伤害替代战斗。

## 验收清单

| 例子 | 所需机制 | 完成标准 |
|---|---|---|
| 闪击、仅移动变体 | 部署事件、行动状态 | 独立自定义词条，不授予内置闪击冒充 |
| 伞降 | 部署位置规则 | 前线候选和执行门户一致，敌方占领/满线拒绝 |
| 固守 | 行动限制、回合监听、随机攻击 | 不消耗普通行动；真实反击/伏击/死亡结算 |
| 化整 | 主动技能、费用/次数、关联卡池开发 | 原生操作按钮，取消和失败不错误扣费 |
| 增援 | 入场历史、卡牌附带效果 | 首次不触发，重入触发；指向/非指向均能结算 |
| 充能 X | 计时、就绪、消费 | 等待使用期间不重充；取消不消费；使用后重新计时 |
| 复员 | 离场原因、复制、费用、移除自身词条 | 复制品无复员，费用按参数加，不重复触发 |
| 不屈 | 消灭前介入、保留血量、延迟任务 | 此次不离场、不发死亡；约定时点真正消灭，防重复拦截 |
| 战略、虎视 | 死亡替代/攻击后、定义替换、撤退 | 溃军是可配置的关联单位定义；替换占位和历史正确 |
| 装填、发射 | 选目标、读取属性、生成卡携带记录 | 多张生成卡分别保存值，源卡变化/离场不影响记录 |
| 游击 | 使用事件、无词条复制、条件期限 | 只移除指定生成实例；离手后不被期限任务误删 |
| 机动 | 额外行动、次数消费 | 额外行动恰一次，移除机动；费用和相互限制正确 |
| 间谍 | 每回合限次、敌方事件、资源调整 | 仅敌方首次消灭该单位时触发，双方回合边界清晰 |
| 缠斗 | 双方关联、行动限制、周期战斗、关系解除 | 不允许自己/友军等无效目标，死亡/变形/离场清理关系 |
| 制空 | 攻击者是空军、目标带词条、本回合击杀记录 | 敌方空军未消灭制空单位前无法攻击友方总部，消灭后解锁 |
| 炎热 X / 寒冷 Y | 词条被授予事件、读取对方词条参数、词条对消 | 静态加成正确；相遇按 X/Y 差值对消或转换，相等双消 |
| 地域（水域/平域） | 战场地形系统、部署门禁、陆军水域裁决 | 水域陆军无潜水/浮水即灭；潜水回合起点扣血；浮水攻击减半 |
| 船类型 | 地形部署门禁、离水惩罚、对船伤害减半 | 仅水域可部署；离水防御 1＋抑制禁移动可攻击；非炮兵陆军伤害减半 |
| 阻击 X | 阵线/位置表达式 | 攻击阻击单位同阵线目标先受 X 伤 |
| 烟幕-标记 | 目标重定向（攻击/指令/部署） | 敌方行动只能指向标记单位；前线无敌且无法移置时不允许标记 |
| 守护-掩护 | 邻接表达式、目标重定向 | 敌方只能攻击掩护单位的相邻单位 |
| 伺掠 | 击杀者判定 | 每回合首次由本单位消灭敌军时获得等同目标费用的指挥点 |

图片表述未明确的时点、复制范围、费用和进场历史保留必须能配置，并在示例里标明选定口径；不能猜测后写死。

已落地词条的口径（机制示范包，见下）：战略＝消灭介入时转化为溃军（本体不实际死亡）；虎视＝被攻击后仍存活的敌方单位转换；复员＝非消灭离场时复制入手、费用 +X、复制品无复员（被消灭不算复员）；增援＝`entries ≥ X` 次进场起触发；不屈＝首次消灭介入保留 1 点，己方回合开始消灭；缠斗＝部署指定敌军、双方禁移禁攻、己方回合开始真实交战一次、任一方离场解除。

## 机制示范包

「机制示范包」（`pack/diy-demo-mechanics`）由 `tests/SeedDemoPackTool.cs` 种入真实工坊库（`SEED_DEMO_PACK=1` 触发）：11 个程序词条（游击/增援/机动/不屈/战略/虎视/复员/缠斗/溃退/装填/发射）各配示范卡，含溃军（战略/虎视的替换目标）与装填→发射（指令卡程序词条链：记录攻击力→生成携带记录的发射→按记录值伤害）。DIY 编译器已放宽：指令卡允许携带包内程序词条（kw-*），内置战斗词条仍禁。

## 当前进度

底层程序模型、参数、状态、条件、规则贡献、生成卡记录、消灭前介入已进入实现。效果攻击与定义替换已经真实对局验证：攻击走原生交战门户（总部血量按攻击力实扣、`unit.attack.before/after` 触发器发火），替换原地换体且旧单位离场。UI 链路已铺通：规则程序编辑器（工坊词条入口）、卡牌词条参数（SpinBox 写回 `KeywordValues`）、战斗内技能面板与 `UseKeywordSkill` 命令（枚举→放行/拒绝→结算，拒绝不扣费不消耗）。`CreateFromCatalogAsync` 已修为目录编译前显式暖机——词条注册面 fail-fast 不再依赖外部启动顺序。

引擎侧 18 项程序专项通过（含机制示范包 8 词条专项：机动/不屈/战略/虎视/复员/缠斗/装填→发射/增援·游击由既有专项覆盖）；过程中修掉两个词条运行时缺陷——`Execute` 对 `target.*` 表达式提前对宿主求值（指令卡/手牌卡误炸），以及复制费用误用行动花费修饰（手牌单位基准未就绪必炸）→ 新增 `DeployCostModAsync`（部署费修饰，手牌可读）。UI 侧 14 项工坊桥接测试通过，全量回归零回归（UI 22 失败＝迁移遗留基线；引擎 1119 项全绿）。
