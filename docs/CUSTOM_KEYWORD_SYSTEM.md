# 自定义对战词条系统（开发中）

目标：Godot 负责编辑与表现，OrC-KSD 负责规则、计时、状态、目标选择和结算。不能将词条名称或几个样例硬编码作为完成标准。

## 统一定义

词条程序包含参数默认值、实例状态、规则贡献、事件处理器及主动技能。行为使用通用操作和条件组合；卡牌引用词条并给出参数。每局冻结程序版本；每个词条实例独立存储状态。生成卡可携带独立键值记录，数值快照不依赖源卡继续存在。

规则组合使用显式优先级，同优先级限制优先；不改变引擎内核 moding 的纯替换语义。候选、费用和执行复验必须保持同源。特殊效果发起的攻击具有明确来源，仍走攻击触发器和真实交战；不会直接伤害替代战斗。

## 验收清单

| 例子 | 所需机制 | 完成标准 |
|---|---|---|
| 闪击、仅移动变体 | 部署事件、行动状态 | 独立自定义词条，不授予内置闪击冒充 |
| 伞降 | 部署位置规则 | 前线候选和执行门户一致，敌方占领/满线拒绝 |
| 固守 | 行动限制、回合监听、随机攻击 | 不消耗普通行动；真实反击/伏击/死亡结算 |
| 化整 | 主动技能、费用/次数、关联卡池开发 | 原生操作按钮，取消和失败不错误扣费 |
| 增援 | 入场历史、卡牌附带效果 | 首次不触发，重入触发；指向/非指向均能结算 |
| 充能 X | 计时、就绪、消费 | 等待使用期间不重充；取消不消费；使用后重新计时 |
| 复员 | 离场原因、复制、费用、移除自身词条 | 复制品无复员，费用按参数加，不重复触发 |
| 不屈 | 消灭前介入、保留血量、延迟任务 | 此次不离场、不发死亡；约定时点真正消灭，防重复拦截 |
| 战略、虎视 | 死亡替代/攻击后、定义替换、撤退 | 溃军是可配置的关联单位定义；替换占位和历史正确 |
| 装填、发射 | 选目标、读取属性、生成卡携带记录 | 多张生成卡分别保存值，源卡变化/离场不影响记录 |
| 游击 | 使用事件、无词条复制、条件期限 | 只移除指定生成实例；离手后不被期限任务误删 |
| 机动 | 额外行动、次数消费 | 额外行动恰一次，移除机动；费用和相互限制正确 |
| 间谍 | 每回合限次、敌方事件、资源调整 | 仅敌方首次消灭该单位时触发，双方回合边界清晰 |
| 缠斗 | 双方关联、行动限制、周期战斗、关系解除 | 不允许自己/友军等无效目标，死亡/变形/离场清理关系 |

## 当前进度

底层程序模型、参数、状态、条件、规则贡献、生成卡记录、消灭前介入已进入实现。效果攻击与定义替换已经真实对局验证：攻击走原生交战门户（总部血量按攻击力实扣、`unit.attack.before/after` 触发器发火），替换原地换体且旧单位离场。UI 链路已铺通：规则程序编辑器（工坊词条入口）、卡牌词条参数（SpinBox 写回 `KeywordValues`）、战斗内技能面板与 `UseKeywordSkill` 命令（枚举→放行/拒绝→结算，拒绝不扣费不消耗）。`CreateFromCatalogAsync` 已修为目录编译前显式暖机——词条注册面 fail-fast 不再依赖外部启动顺序。引擎侧 10 项程序专项通过；UI 侧 14 项工坊桥接测试通过，全量回归零回归（22 失败＝迁移遗留基线）。完整样例（上方验收清单 14 例逐条落地）、导出升级验收与实机 `--capture-real` 通道仍在开发，不能以这些初步结果宣布系统完备。
