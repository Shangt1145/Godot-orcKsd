## 实现

- 保存真实松手姿态，排队时保留卡牌位置；演出接手同一姿态，避免回到手牌后重新起飞。
- 正常速度下，直接进入最后展示位置约0.18秒，向左上方完整移出屏幕约0.44秒；停靠后阅读1.5秒，卡牌本身共约2.12秒（按用户反馈延长停留，命中同时播放）。去掉中央停留、右侧展示和普通模式的淡出。敌方指令从可见手牌背面位置接入同一段演出。
- 受击与指令退场同时进行；无受击目标的指令不再额外等待1.22秒。
- 单目标指令拖拽时卡牌留在手中，拖出箭头指向单位；合法单位高亮，松手直接提交该单位UID。空地、非法目标及右键取消不提交出牌、不消费费用，不弹出二次目标选择窗口。
- 目标投影和实际效果共用桥接层的筛选条件，界面不解析卡牌文案推断规则。普通抽牌、全体效果指令仍拖出卡牌。
- 二／三选一在桌面展开真实候选卡面，约0.32秒进场，各牌相隔0.06秒；卡牌候选从背面翻出，抉择分支沿用源牌插画、展示各分支原文。点选后约0.26秒收拢，未选牌翻回背面退场，选中卡面直接接最后展示段及0.44秒左侧退场，不重复起飞或停留。
- 点击空白、右键或Esc取消抉择，原牌约0.26秒回到手牌；拒绝选择时允许重新选择。连续两次三选一的请求各自结束，前一次关闭通知不会关闭下一次。
- 反制挂起／解除保留真实松手姿态，约0.56秒回到原手牌位置，同时显示窄条提示；只保留一个可见卡牌实例。费用预留／退款及触发条件仍由引擎给出，敌方挂起保持匿名。
- 选项和候选卡来自引擎请求；桥接层额外提供发起选择的源牌并冻结快照。本次补充演出和交互，没有扩展卡牌效果支持集；三选一候选动画通过独立视觉场景验证，实际支持卡的两个抉择分支由真实引擎测试验证。
