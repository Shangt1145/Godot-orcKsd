|---|---|---|

| `deck.shuffled` | 只有演示/调度动作 | 本方与敌方洗牌的匿名提示和音效，不传牌库内容 |
| 认输 `Match.Concede` | 无入口，静默终局不能交付结果 | 友方回合菜单“认输”，可继续对局或确认；引擎判定胜方，投递一次结果，终局立即禁用战场操作 |
| 总部致死 | 原生零血对象被当作尚存总部 | 原生致死攻击产生总部毁灭，胜负面板不复活零血总部；保留引擎终态 DTO |
| 结束后重开及退出待选 | 未覆盖真实认输与待选重开 | 旧局输入、动画、选择立即清理；新 MatchId、新换牌，旧 responder 无法回答新局 |

所有规则与效果仍由引擎执行。桥接读出事实，界面只显示。原生升级保留原卡 Definition/UID，仅替换引擎内容；没有捏造新卡身份、名称或卡图。终局在已接受演出之后播放，终局之后不再播放反馈或恢复操作。

无事件变化的序号属于客户端表现序列：保持递增，不伪装成引擎发射的事件。原生段的既有历史快照限制仍见接入基线。

## 支持范围

生产支持集仍为 21 种审核卡，卡组准入没有放宽。当前审核指令的强化、闪击/费用修改和总部防御增益已使用真实效果验证。老兵/隐蔽通用读取与事件接入使用原生定义和原生机制验证，没有将未经审核的原始卡加入产品牌组。

本轮完成真实战场反馈与终局接通；效果编辑器的可视化创作流程、复杂反制的打断时机与公开费用、原始老兵/揭示卡的逐张效果装配仍待接入。没有把这些功能标为已完成。空牌库疲劳依旧遵循当前引擎能力。
