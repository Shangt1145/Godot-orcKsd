# 词条使用正常拖拽行动

对战界面移除了词条主动技能按钮。现有机制示范包的 11 个词条均使用持续规则或事件触发，不需要主动技能按钮。编辑器默认只提供持续规则和事件行为，旧主动技能原始数据保留并提示改写。

- 溃退：原生新增通用 `move.retreat` 规则点。满足行动资格的前线单位可拖回己方支援线的空槽；可用性与执行复验使用相同方向判定，正常扣除行动费、消耗移动机会并发出移动事件。不会用免费撤退效果代替移动。没有权限的普通单位不能后撤。
- 机动：示范程序使用 `attack.limit=2`，监听本单位第二次实际攻击完成后移除自身词条。两次均拖箭头到敌方目标，各自付费；取消不计次数，第三次不能攻击。
- Godot 投影保留原生移动候选的阵线和槽位；支援线显示可落点与后撤提示。规则执行仍在 OrC-KSD。
