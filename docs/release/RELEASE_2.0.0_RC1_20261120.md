# OrC-KSD 2.0.0-rc.1（2026-11-20）

这是 OrC-KSD 2.0.0 的第一个候选版，包含 beta.13 的积木 Inspector，并加入联机自定义桌饰同步。

## 联机桌饰

- 装备自定义 GLB 桌饰后，双方都能看到两侧的模型，并在自己的客户端点击。桌饰同步静态模型、大小和朝向。
- 原模型动画、点击设置和播放状态留在本机。接收方点击远端桌饰时，显示本地轻晃反馈。
- 桌布仅在装备者的客户端显示。旧房主程序仍提供桌饰预览图。完整模型同步需要更新房主程序及双方客户端。

## 安装与升级

- Windows：新安装请完整解压 ZIP，再运行 `KardsUi.exe`。beta.13 提供对应已公开构建的增量补丁。联网启动旧版，等待下载完成并正常退出，再启动新版。
- Android：下载 APK 覆盖安装，保留原应用数据。安装代码为 25。客户端会提示新版，并打开 GitHub 发布页供手动下载安装。

## 已知边界

- 规则文本与积木分别编辑。自定义规则「下个回合开始时」和「对敌方总部造成伤害后」的已知执行适配缺口仍在。
- Android 实体机兼容性仍待验证。

## 源码构建

引擎基线为 `c950b2a`，构建应用了 [目标编写补丁](../engine/v4-visual-target-authoring-20261114.patch)、[Android 房主脚本执行器补丁](../engine/v4-mobile-server-script-evaluator-20261114.patch)和[联机桌饰补丁](../engine/v4-network-desk-model.patch)。
