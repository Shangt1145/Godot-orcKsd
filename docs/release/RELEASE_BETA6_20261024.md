# 0.0.0-beta.6（2026-10-24）

## 本版变化

- 修复新旧机制接口的兼容问题：替身/离场后的攻击收尾、独立发射的参数回退。
- 修复回合抽牌提前闪入手牌、部分数字基线、缠斗部署与指向反馈；加快多单位演出。
- 接入原版卡背、总部纹理、中文字体和普通/特殊表情，支持搜索、分页、国家筛选、预览与保存。
- 联机同步外观、双方视角表情底图、颜色与通讯状态；重连后恢复装备；总部规则不变。
- 修复旧卡包原生脚本在预选靶后再次要求玩家选择的问题。复用预选结果仍通过原生选择器验证，不直接执行伤害或消灭。
- 保留已完成桌饰资源；按用户要求暂停其后续动作与音效开发。

## 多人能力：尚未形成任意 DIY 联机闭环

| 流程 | 当前支持情况 |
|---|---|
| 本地创建、编辑、保存及导入导出 DIY | 支持已有编辑器所能表达、执行的内容；不是任意自定义规则均已验证 |
| 本地卡组构筑及单机使用 | 支持现有准入范围内的内容 |
| 两人联网对战 | 支持房间、座位批准、原生出牌/选靶、换牌、回合、认输、重连；须网络可达 |
| 自建构筑卡组联网 | 仅接受已装载卡池中的 `pack/` 卡，当前房间要求 39 张牌 |
| 各玩家携带 `diy/` 卡直接开局 | 不支持：房间入口会拒绝该标识 |
| 自动分发 DIY 规则与卡图 | 尚未接通完整界面与协议流程；外观 PNG 同步不等于规则包同步 |
| 多人协同编辑同一卡包、三人以上同局 | 本版未提供 |

已在本机多客户端验证联机流程；不把它称为跨公网、不同机器的完整长局验收。
原始卡池中仍有 13 张无有效效果的卡被准入过滤；不开放为已验证可玩卡。
原版动态表现的逐帧时间、声音尚未完整核对。
