# 2.0.0-beta.4（2026-11-05）

PC 与 Android 同步功能发行。沿用整代版本 `2.0.0`，预发布序号从 `beta.3` 递增到 `beta.4`。

本版有三件事：**启动自动更新**（以后不用手动找补丁）、**复杂 DIY 全链路打通**（画布保存的效果
真能进对局）、**对战桌面迁到共享 3D 世界**（含自定义桌布与桌饰）。

## 更新内容

### 启动时自动检查更新

以前每个版本都要手动找补丁、下载、跑更新器——玩家麻烦，发版的人更麻烦。本版起：

- 游戏启动后**后台**查一次发布页，发现新版就弹一句「可以用增量补丁更新（7.1 MB）」；
- 玩家点「现在更新」→ 下载到 `user://updates` → 校验 SHA256 → 交给游戏目录里的
  `更新游戏.exe` 应用 → 装完自动重新打开；
- 也可以「跳过这个版本」，那个版本以后不再提示。

三处刻意的边界：

- **开发环境与探针不查**。编辑器里没有构建清单、也没有构建 id，查了只会误报；
  `--verify-*`／`--capture-*` 要的是确定性，网络一抖就会让同一份脚本给出两种结论。
- **检查失败绝不拦启动**。没网、被墙、接口抽风都是常态，一律只写日志。
- **游戏自己不替换任何文件**。正在跑的进程锁着自己的 dll 与 pck，替换必然失败；
  它只负责下载、校验、拉起更新器再退出。替换与回滚仍由更新器做（那边有日志、校验和回滚）。

补丁按**构建 id** 匹配（不是版本号）：同名版本的两次构建字节不同，补丁打不上。
对不上本机构建时依次退到「兼容合集补丁」→「完整包」；都没有就**不提示**，绝不拿旧版本凑数。

### 复杂 DIY：从画布到对局打通

- **`choice` 接通了**。它以前标着预览态（运行期无条件抛），现在复用既有的选靶通道：
  选项文案即标识集，提交的是 1 基序号。选项文案空、纯空格、重复都会在校验期被点名——
  否则玩家会看到两个一模一样的按钮，或者点了没反应。
- **画布能保存到卡包了**（工坊 →「词条与效果」→「用积木搭…」）：DSL 文档 → 草案 → 摊平产物
  一次写完，产物自包含、带双哈希；保存后立刻检查一次，把「草案落后于父」显示出来。
- **能改一个已有的效果**：产物落到 `<原 id>.dsl`，包内引用它的卡自动改指产物，原效果保留。
  引擎不允许产物 id 等于父 id（读写同一个文件），所以走的是等价路径，不是真覆盖。
- **父效果换成模板**：引擎 R39 之后，具体效果的成员不再允许被覆写，父必须是声明了空位的模板。
  本版从引擎的模板库派生 104 份（信号 × 守卫档），并照抄模板的挂载、视图与生效时机。
- **目录与视图改读引擎**：节点目录来自引擎扫描（扫描不可用时退回本地镜像，并**照实说明**），
  视图字段来自父成员声明。
- **多输出节点可用了**：`fetchFromDeck`／`pickHandCards` 这类两输出的节点以前只能丢结果，
  现在按输出名逐个命名（键集必须恰好等于输出名）。
- **27 条契约 check 向量跑起来了**，与后端结论**逐字一致**。首跑 21 过 / 8 败——五处分歧都在
  我们的判定上（`stop`／`interrupt` 没补、循环上限报了两个码、空 `else` 没报、`schema-version`
  路径少一层、`script` 的引脚数组没建模）。这些错都不会让画布打不开，只会让提示指错地方。

### 3D 战场与桌饰

- 对战桌面从「一张贴图 ＋ 每件桌饰独立子视口」改成**一个共享 3D 世界**：相机、桌面、单位、
  总部、牌堆、特效、桌饰在同一个场景里参与遮挡、光照与投影。卡牌是有厚度的薄网格，
  卡面仍由现有 2D 绘制提供纹理。
- 规则不变：屏幕命中经相机射线，但**部署、选靶、提交仍走既有投影与候选 id**，
  不用物理碰撞替代引擎规则。
- 桌布／桌饰：导入 PNG/JPG/WebP 作桌布（跟随当前卡组），导入图片或 GLB 作桌饰
  （大小 0.25–3、朝向 ±180°、四种点击演出）。设置里可切「倾斜战场视角」（默认平直俯视）。
- **诚实边界**：随包的 51 份原版 GLB 都没有内嵌动画，所以轻晃／转圈／抬起是可配置的**程序演出**，
  不是还原了原版专属动作。自定义 GLB 与其动作配置目前**只有本机能完整看到**，对手看到预览图。

## 安装与更新

- **Windows 已安装 beta.3**：启动游戏即可自动提示更新（beta.3 → beta.4 单条补丁）。
  也可以手动用更新器 **1.2.0** 应用同一条补丁。
- **Windows 在 beta.1／beta.2**：本版只发 beta.3 → beta.4 一条补丁，请先按 beta.2 → beta.3 的补丁
  链升到 beta.3（自动更新只认「本机构建 → 本版」）。全量包按仓库规则不在线上分发。
- **Windows 新玩家**：下载完整包解压即用（包内含 `更新游戏.exe`，之后就能自动更新）。
- **Android**：下载本版 APK 覆盖安装。Android 走完整 APK，不使用 `.orcupdate`。
- 源码对应标签 `v2.0.0-beta.4`。构建所用引擎提交 `ce498aa552bb44300e69f5e9a11605f6ef1f1002`
  （本地 v4 分支，含 R39／R40）。

## 已知问题

- 契约包的目录快照不带 `builtInOps`，而引擎的运行期 DTO 要求它非空——只读契约包的前端拿不到
  内建 op 的能力分区。已提引擎 issue #5，本版在客户端侧自解析规避。
- 引擎 `ModingFlattener.Check` 没有 `templateRoot`：父是模板时，「父新增成员而产物没有」
  这条陈旧检查静默跳过，只剩 DSL 哈希比对。已提 issue #3。
- 桌布与桌饰的**完整模型同步**还没做：联机时对手只看到预览图。
