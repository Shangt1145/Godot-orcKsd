# 2.0.0-alpha.6（2026-10-28）

PC 与 Android 同步功能发行。沿用整代版本 `2.0.0`，预发布序号从 `alpha.5` 递增到 `alpha.6`。
本版是 alpha 收口的最后一版：`P1`–`P8` 的欠账全部关闭，对外承诺要么兑现、要么写明降级。

## 更新内容

### 联机

- **房间可起名**：局域网房间列表显示的就是房主起的名字，改名不必重开房间（下一轮广播即生效）。留空时仍显示"好友的房间"。
- **可固定端口**：并直接写明"公网联机要在路由器把 TCP 端口映射到本机；局域网或虚拟局域网直连不用"。
  固定端口被别的程序占用时**不静默换端口**，而是退回自动分配并说明原因。
- **加入失败会自己重试**：连接层瞬时故障退避重试 3 次；`拒绝连接 / 超时 / 找不到地址 / 网络不通` 翻成人话；
  房间已满或已开局是明确结论，不重试，直接给「重试加入 地址:端口」。
- **「入场申请」升级为「房间成员」**：上半是待处理申请（批准/拒绝），下半是已连接的人（移除）。
  移除即断开并释放座位；**对局中移除等同于该座位认输**，确认页写明。
- **掉线重连补了两处死路**：大厅阶段断线后「重新申请入场」按钮以前永不出现；房主对局中掉线重连后战场以前永久冻结。

### 对局内

- **行动记录面板**：三个页签——战报（完整行动序列，只读）、弃牌堆（弃牌与手牌上限烧掉，两方分开）、
  词条（带参数值与携带者）。战报条目只来自引擎给的表现步骤与前端自己发起的动作，**不推断规则、不补数字**；
  上限 2000 条，超出丢最旧并写明条数。
- **回合倒计时**：我方回合可见（75 秒，最后 20 秒变色）。**超时只提示，不结束回合**。
- 弃牌演出补齐弃牌堆落点；对手的弃牌只显示张数，**不带牌面**。

### DIY 与卡组

- **结构化选靶**：效果编辑的目标选择改为结构化节点（选择/过滤/空目标都有明确语义），单目标走声明图，玩家选谁打谁。
- **卡包整包导出/导入**：清单 + 卡牌 + 卡图走 ZIP 往返。
- **能力目录诚实化**：检查器动作目录与引擎实现对齐，按「alpha 可用 / 预览」分区，写明每项编不出来的原因。
  **161 项不等于全部机制都能跑**。
- **存档与卡牌 ID**：卡库/卡组/工坊统一走版本判定（区分"存档比游戏新"与"格式太旧"，都保留原文件并说明）；
  卡牌改 ID 后卡组引用自动重新绑定。
- **卡库环形备份（本版新增）**：卡库、卡组、工坊每次保存前留上一版，最多 3 份
  （`cards.json.bak1` → `.bak2` → `.bak3`）。读失败时提示行会直接说明备份在哪、改名覆盖即可回滚。
  **备份写不出去就让这次保存失败**——"以为有后路其实没有"比直接报错更糟。

### 手机

- **切后台回来会明说连接状况**：回前台先真发一次请求确认连接，再给结论——正在确认 / 正在重连 / 已恢复 / 没恢复。
  单机对局与 3 秒以内的切出不提示。提示是顶部横幅，不挡操作。
- 回到前台会重新点亮 Android 前台服务（系统在后台可能回收它，界面上看不出来）。
- 服务端子进程随 UI 退出：引擎侧 `--parent-pid` 看门狗，实测只杀 UI（不带 `/T`）时子进程 2.1 秒内退出、端口可重新绑定。

## 不包含（明确降级，不要理解成"支持"）

- **没有房间密码**。服务端协议没有口令字段，客户端自校验等于假安全。房间真正的门是房主逐条批准入场。
- **没有观战延迟**。不绑座的观战者是全知的（能看到双方手牌），延迟只把泄牌推后几十秒。
- **内建词条释义只覆盖 11/19**。其余在词条页明说"引擎未提供"，不编释义。
- **战报不记资源点变化与逐张抽牌**（刻意，理由在 `BattleLog` 类注释里）。
- **手机切后台的提示没有真机验证**。桌面不发 `paused/resumed`，行为只在桌面探针里验过；
  ARM64 已打包但**没有实体手机实测**，本版不宣称真机通过。

## 验证记录

- 客户端测试 **705 项通过**、0 跳过（alpha.5 为 626）。
- 整轮 UI 探针：`UI_VERIFY_OK screens=12 cards=534 texture_cache=64/64`。
- 相关专项探针：`-VerifyBackground` → `BACKGROUND_RECOVERY_VERIFY_OK`；
  `-VerifyDiy` → `DIY_UI_VERIFY_OK`（效果行 ↑/↓ 已改为真点击，不再是 skip）；
  `-VerifyRoomSettings` / `-VerifyDiscard` / `-VerifyDecks` 全绿。
- 服务端子进程随 UI 退出（端到端实测）：只杀 UI、不带 `/T`，
  `childExited=True elapsed=2.1s portRebindable=free parentPidMatches=yes` → `WATCHDOG_OK`。
- 引擎测试：`Orc.Game.Tests` **1360/1360 通过**，`Orc.Ai/Mcp/Packages/Manager` 全绿。
  **`Orc.Server.Tests` 127 项里有 1 条时序用例在整机满载并行跑时偶发失败**
  （`MatchStartedNoticeTests.BothSeatsReceiveMatchStarted_BeforeTheirFirstView`，断言"房主侧收到入场信号"时没有等待，属用例自身的竞态）；
  该用例单独复跑 **5/5 通过**，与本版改动无关。这里如实记下，不当作"全绿"。
- 升级路径实测：alpha.5 完整包解压后打本版补丁 → 真实更新器 `GODOT_UPDATER_VERIFY_OK` →
  逐文件校验一致 → 玩家自己放的文件未被改动 → 升级后的 EXE `EXPORT_VERIFY_OK`。
- 打包后 EXE 冒烟：`EXPORT_VERIFY_OK` + `WORKSHOP_VERIFY_OK`。

## 安装与更新

- **Windows 已装 alpha.5**：用更新器 **1.2.0** 应用本版唯一补丁
  `OrC-KSD-2.0.0-alpha.6-from-E78E6CD6D59B-to-12CD07C37C83.orcupdate`（6,908,561 字节）。
  游戏版本与更新器版本独立，更新器不必随游戏升。
- **Windows 新玩家**：按 alpha.1 全量 → alpha.2 补丁 → alpha.5 补丁 → 本版补丁的顺序走。
  超过 1 GB 的 Windows 全量包按仓库规则留在本机 `dist/releases/2.0.0-alpha.6/full/`，不上传 GitHub。
- **Android**：下载本版签名 APK 覆盖安装。本包含 `arm64-v8a` 与 `x86_64`，
  安装版本号 `versionCode=11`，版本名 `2.0.0-alpha.6`。Android 走完整 APK，不使用 `.orcupdate`。
- **源码**：对应标签 `v2.0.0-alpha.6`。从公开引擎 `a0b3511cc19230237d2e7dbd2fc60f7569199ff5`
  构建时应用上面的累计引擎补丁，**不要再叠加历史补丁**。
