# 2.0.0-beta.2（2026-11-01）

PC 与 Android 同步功能发行。沿用整代版本 `2.0.0`，预发布序号从 `beta.1` 递增到 `beta.2`。
本版新增**积木式效果编辑面**，并把界面上的专业术语统一换成作者能读懂的日常说法。
按常规版本产出 Windows 全量、增量补丁、更新器与 Android APK。

## 更新内容

- **新增积木式效果编辑面**（`效果搭建` 屏）：左侧工具箱列出引擎当前支持的全部 **37 块积木**
  （10 个内建 op ＋ 27 个目录动作），按用途分组、带分组色脊、可搜索；点一块就插到画布上
  当前选中的位置，插入后画布自动滚到新块。画布按 Scratch 的**形状**读（缺口／凸榫／C 形
  子体），配色换成本项目的军绿＋黄铜＋羊皮纸土色系，不用 Scratch 那套高饱和色。
- 编辑面**只产出 `.hdsl.json`，不生成 csx**；右栏实时显示生成内容与本地检查结果，装载期由
  后端最终裁定。支持撤销／重做，检查结果按「第几块 · 哪一项」指位置，原始错误码与契约路径
  留在 tooltip。
- 契约 v1（2026-11-01 版）对齐：`read.of` 支持**实体表达式**（读被遍历的那个单位自己的属性）、
  可读项按**实体种类**（unit／hq／player）分组、新增只读查询原语 `unitsOf`、`bind` 按**节点级
  字段**处理（不再当成引脚）、`choice` 的 `options` 按 `[{label, actions}]` 处理、`script`
  补空的 `inputs`／`outputs` 数组。
- **界面术语简化**：绑定→起个名、表达式→值、引脚→格子；`输出 .hdsl.json`→`生成的内容`、
  `本地校验`→`检查结果`；算子 `le`／`ge` 显示为「小于或等于／大于或等于」；`‹f›.defense`
  显示为「‹f›的防御力」；错误码 `pin-missing` 显示为「还有地方没填」。只翻显示，写进文档的
  仍是原名（契约不允许别名）。
- 新增 `choice` 节点的编辑：每条选项＝一句话 ＋ 自己的一串动作，可增删。
- 引擎侧**未改动**：本版把 11-01 引擎更新的逐项核对写成文档（`docs/engine/ENGINE_UPDATE_20261101.md`），
  引擎仓库只读使用。

## 安装与更新

- Windows 已安装 beta.1：用更新器 **1.2.0** 应用本版唯一的 beta.1 → beta.2 补丁
  （22.7 MB，相对 1.22 GB 全量省 98.1%）。
- Windows 新玩家：按仓库发行规则，超过 1 GB 的全量包在 `dist/releases/2.0.0-beta.2/full/`
  本地保留、不上传；需要时从本机发行目录取。
- Android：下载本版 APK 覆盖安装。`versionCode=13`，版本名 `2.0.0-beta.2`，包含
  arm64-v8a 与 x86_64。Android 走完整 APK 更新，不使用 Windows 的 `.orcupdate`。
- 源码对应标签 `v2.0.0-beta.2`。构建所用引擎提交 `169e57518763e1b80c4bae4a1b39023ad4c0b221`
  （本地 v4 分支；**未**包含 `origin/main` 上 11-01 的 `62fcabf`／`d366c85` 两个提交）。

## 保留的边界

- 编辑面**没有写回**：不接 `AssetEditor.Commit`，不产出 `.moding.json` 草案，卡牌草稿里的效果
  仍是原来的文本形态。这是下一版的第一件事。
- 目录用内置**镜像快照**，未接 `HandlerCatalogFacade`；视图字段是 3 个演示字段，未接
  `DescribePrefab`；`script` 节点可插入但没有值通道；多输出节点的 `bind` 对象形态界面不做
  （校验器会如实报 `bind-scope`，不会默默放过）。
- 目录里 `subtypes` 的声明在真实目录中仍为 **0** 条，所以实体子类型交集判定暂时不会在真实
  数据上触发——是数据缺口，不是契约缺口。
- 本版未重新生成官方卡池，既有解析覆盖与生成物欠账未因本次发版消除。
