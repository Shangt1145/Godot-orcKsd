# 2.0.0-beta.7（2026-11-07）

PC 功能发行。沿用整代版本 `2.0.0`，预发布序号从 `beta.6` 递增到 `beta.7`。

本版只做一件事：**把下载做结实**。beta.6 的自动更新流程已经对了，但下载本身在慢网下有两个坑，
都会让玩家「永远等不到更新」。

## 更新内容

### 下载断了能接着下

补丁 40 MB、网络 30 KB/s 的时候，玩家只要提前退出一次就永远更不完——因为旧代码在失败时
把半截文件（`.part`）**无条件删掉了**，下次从零开始。

现在：

- 断线**保留** `.part`，下次带 `Range: bytes=N-` 从断点续；
- 只有**内容坏了**（长度不符／哈希对不上）才删——那种情况接着续只会一直失败；
- 服务端忽略 `Range` 回了 200 时**从头重下**，绝不往已有内容后面追加：
  那样会把前半段拼两遍，长度恰好对得上、只有哈希不对，是最难查的一种坏包；
- 服务端回 416（范围不成立）＝本地这份已经不少于远端，直接交给长度与哈希去判。

### 已经下完的不再重下

更新是**退出时**才应用的。玩家下完却没退出、或者退出时更新器没来得及动手，
下次启动会把 40 MB 再下一遍。

现在先看目标文件在不在、长度与哈希对不对：对得上就直接用，一次请求都不发。

## 已知问题

- **Android：本版仍然不发 APK。** 保留上一版数据覆盖安装后进程会在 1 秒内退出
  （`pm clear` 清空数据后同一个包能正常启动，上一版在同样的旧数据上也能启动）。
  从 beta.3 覆盖安装是现有安卓玩家唯一的升级路径，在这条查清之前不发。Android 侧仍是 `2.0.0-beta.3`。
- **单位换线的画面表现**：有反馈说单位移动到前线后位置与动画不对。为此加了只看画面的探针
  （`--verify-move-motion`），但目前**两条命令路径都复现不出来**（439 → 267、抬升峰值 0.42、落定无偏差）。
  本版没有修它，只是把它变成可测的。
- 契约包的目录快照不带 `builtInOps`（引擎 issue #5）；`Check` 缺 `templateRoot`（issue #3）。

## 安装

- **Windows**：从 **beta.3／beta.4／beta.5／beta.6** 都能升。本页挂的是**兼容合集补丁**，
  里面装了几个源构建的变体，更新器按本机构建 id 自己挑。
  - 已在 **beta.6**：启动游戏会自动下载（断了会续），退出后生效。
  - 更早的版本：下载本页补丁，用游戏目录里的 `更新游戏.exe` 手动应用。
  - 全新安装：需要完整包（约 1.2 GB），按仓库规则不挂在本页。
- **Android**：本版不发，仍是 `2.0.0-beta.3`。
