# 2.0.0-beta.7（2026-11-08 补发）

PC 功能发行。沿用整代版本 `2.0.0`，预发布序号从 `beta.6` 递增到 `beta.7`。
beta.7 此前只有提交与说明、未出包、未打 tag；本次补发，并把工坊异画一并纳入。

本版做两件事：**工坊异画**（完整卡面替换与实时数值定位），以及**把下载做结实**（断点续传、已下载复用）。

## 更新内容

### 工坊异画：整张卡面 + 手动数值定位

入口：DIY 工坊 → 打开卡包 → 打开卡牌 → 卡图 →「异画与数值位置…」。异画是**卡牌级展示设置**，不是卡组外观装备：

- 只导入包含卡框、卡名、插画与规则文字的**完整卡面**；不提供插画／卡框分层编辑，不重新拼装模板，也不叠加卡名或规则文字。
- 图片格式、像素尺寸、宽高比与文件体积均不限制，原图字节原样保存（不缩放、不重编码、不裁剪），文件名 `alt-<SHA256>.<原扩展名>`；Android 文档同样按原始字节读取。设置随兼容卡牌草稿或原生卡包草稿保存，并随卡包导出／导入，导入后可继续编辑。
- 单位卡可逐项定位部署费用、攻击、防御／剩余生命、行动费用；指令与反制只有部署费用。拖动预览彩框或输入 X/Y/宽/高百分比，可设置数字颜色与用于遮住原印数的覆盖底色。**数值按卡面百分比对齐的口径不变**，动态数值只读引擎视图，隐藏卡仍显示背面，CardId、效果与规则定义不变。
- 收藏、构筑、工坊预览、手牌与场上读取同一份设置，按 CardId 生效；不使用外观装备或房间外观同步通道。

### 下载断了能接着下

补丁 40 MB、网络 30 KB/s 的时候，玩家只要提前退出一次就永远更不完——因为旧代码在失败时
把半截文件（`.part`）**无条件删掉了**，下次从零开始。

现在：

- 断线**保留** `.part`，下次带 `Range: bytes=N-` 从断点续；
- 只有**内容坏了**（长度不符／哈希对不上）才删——那种情况接着续只会一直失败；
- 服务端忽略 `Range` 回了 200 时**从头重下**，绝不往已有内容后面追加：
  那样会把前半段拼两遍，长度恰好对得上、只有哈希不对，是最难查的一种坏包；
- 服务端回 416（范围不成立）＝本地这份已经不少于远端，直接交给长度与哈希去判。

### 已经下完的不再重下

更新是**退出时**才应用的。玩家下完却没退出、或者退出时更新器没来得及动手，
下次启动会把 40 MB 再下一遍。

现在先看目标文件在不在、长度与哈希对不对：对得上就直接用，一次请求都不发。

## 已知问题

- **Android：本版仍然不发 APK。** 保留上一版数据覆盖安装后进程会在 1 秒内退出
  （`pm clear` 清空数据后同一个包能正常启动，上一版在同样的旧数据上也能启动）。
  从 beta.3 覆盖安装是现有安卓玩家唯一的升级路径，在这条查清之前不发。Android 侧仍是 `2.0.0-beta.3`。
- **单位换线的画面表现**：有反馈说单位移动到前线后位置与动画不对。为此加了只看画面的探针
  （`--verify-move-motion`），但目前**两条命令路径都复现不出来**（439 → 267、抬升峰值 0.42、落定无偏差）。
  本版没有修它，只是把它变成可测的。
- **异画是本地展示设置**：不走房间外观同步，联机双方需各自安装同一个卡包才会看到同一张异画；
  任意宽高比的完整卡面会整张铺满卡牌矩形（拉伸显示），数值框仍按同一套百分比对齐。
- 契约包的目录快照不带 `builtInOps`（引擎 issue #5）；`Check` 缺 `templateRoot`（issue #3）。

## 安装

- **Windows**：本版补丁从 **beta.6 完整包**升级（单基线）。
  - 已在 **beta.6**：启动游戏会自动下载（断了会续），退出后生效；也可下载本页补丁，
    用游戏目录里的 `更新游戏.exe` 手动应用。
  - 还在 **beta.3／beta.4／beta.5**：先用 beta.6 的兼容合集补丁升到 beta.6，再升本版。
  - 全新安装：需要完整包（约 1.2 GB），按仓库规则不挂在本页。
- **Android**：本版不发，仍是 `2.0.0-beta.3`。
