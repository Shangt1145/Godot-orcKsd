# 2.0.0-alpha.5（2026-10-25）

PC 与 Android 同步功能发行。沿用整代版本 `2.0.0`，预发布序号从当前源码的 `alpha.4` 递增到 `alpha.5`；`alpha.3` / `alpha.4` 为未正式发布的内部构建。本版新增调试功能，按常规版本产出 Windows 全量、增量及 Android APK。

## 更新内容

- 控制台升级为图形化游戏调试台：检查对局、卡牌实时属性、词条、原生效果钩子和属性修饰；本地对局可抽牌、增加双方资源、生成卡牌、召唤单位、造成伤害/回复、设置属性、沉默/消灭、控制自动对手和推进回合。联机及回放只提供诊断查看。
- 修复部署指向：单位的落点与效果目标独立提交；拖到空位后可继续选择目标；取消发生在部署和扣费之前。动态生成的卡牌也能走完整预打出选靶。
- 合入此前尚未推送的跨段目标复用：后半段“其”继续指向前半段选中的单位，不在回合结束时重新选靶。
- 合入原生工坊卡包、扩展包及可编译 DIY 卡的联机会话打包、同步与开局校验。双方客户端和服务端应一同更新。
- Android 使用完整解析器，支持内置房间服务、系统文件导入导出、图片导入和 APK 更新入口；与 PC 共用图形化调试及部署选靶代码。
- 版本脚本同时更新 `VERSION`、游戏显示版本及 Android 安装版本；本版 Android `versionCode=10`，版本名 `2.0.0-alpha.5`。

## 安装与更新

- Windows 已安装 alpha.2：使用更新器 **1.2.0** 应用本版唯一的 alpha.2 → alpha.5 补丁。
- 本页同时提供经过本轮升级验证的更新器 1.2.0 构建；游戏版本与更新器版本独立。
- Windows 新玩家：下载 [alpha.1 全量与更新器](https://github.com/Shangt1145/Godot-orcKsd/releases/tag/v2.0.0-alpha.1)，先应用 [alpha.2 补丁](https://github.com/Shangt1145/Godot-orcKsd/releases/tag/v2.0.0-alpha.2)，再应用本版补丁。按仓库发行规则，超过 1 GB 的新 Windows 全量包在本机 `dist/releases/2.0.0-alpha.5/full/` 保留，不上传 GitHub。
- Android：下载本版签名 APK，覆盖安装。本包包含 arm64-v8a 与 x86_64；Android 通过完整 APK 更新，不使用 Windows `.orcupdate`。
- 源码对应标签 `v2.0.0-alpha.5`。从公开引擎提交 `a0b3511cc19230237d2e7dbd2fc60f7569199ff5` 构建时，应用 [alpha.5 累计引擎补丁](../engine-patches/alpha5-engine-20261025.patch)，已包含本地四个配套提交及本轮修复；不要再叠加历史补丁。
