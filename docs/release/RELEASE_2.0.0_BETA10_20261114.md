# 2.0.0-beta.10（2026-11-14）

Windows DIY 工坊更新。Android 本版不发 APK，沿用 beta.9 记录的旧数据覆盖安装问题。

## 更新内容

- 新增 DIY 引导教程，六步制作闪击、部署抽牌的补给步兵，检查实际编辑结果。
- 效果编辑入口统一到积木 Inspector，移除旧 Inspector 和旧效果编辑页。
- 修复卡牌新效果缺少引用、已有积木重开、保存选项覆盖画布及 .dsl.dsl 后缀链。
- 原生卡牌新增应用并用于构筑、应用并试打，菜单和手机返回接入未保存保护。
- 旧 DIY 卡牌与词条保留原件，通过原生工作副本编辑；无积木源文件的脚本需重新搭建。

## 用户更新

- beta.9：启动游戏联网检查并后台下载，下载完成后正常退出，更新器应用补丁；下次启动核对页脚 beta.10。
- 手动：下载本版 .orcupdate，退出游戏，运行游戏目录里的“更新游戏.exe”，选择游戏目录和补丁后更新。
- 第一次使用更新器：解压 OrC-KSD-offline-updater-1.2.0-win-x64.zip，再运行“更新游戏.exe”。
- beta.8 或更早：本版补丁仅适配 beta.9 构建。先按已有版本的补丁链升到 beta.9，或使用本版完整包安装到新目录。
- 新玩家使用完整 ZIP，完整解压后运行 KardsUi.exe。完整包超过 1 GB，按仓库规则本地交付，不上传 GitHub Release。
- 卡组、DIY、卡图和设置保留在同一 user:// 数据目录。更新失败重新运行更新器；需要撤回时使用“回退上一版”。

## 已知边界

Android 本版不发布；联机不传输卡包，双方须自行安装对应卡包；没有旧脚本到积木的通用无损反编译。

积木与教程相关测试 70 项通过；原生工坊、菜单导航、教程及真实试打通过。发行门禁与补丁实际升级结果见交付目录 verification 日志及 notes/offline-update-report.json。
