# OrC-KSD 2.0.0-beta.12（2026-11-15）

本版重做 DIY 工坊、卡牌编辑界面和积木 Inspector，恢复原生卡牌自动解析入口，并修复更新过程没有可见状态的问题。

## DIY 与 Inspector

- 工坊首页直接搜索、筛选、打开卡包；创建卡包和扩展包保留原生草稿与基础包关系。
- 卡牌编辑采用分区表单与实时卡面预览，保存草稿和应用修改有明确入口。
- 积木工具箱对齐当前引擎开放的 42 个节点，节点、输入输出及已知枚举显示中文。
- “对一个目标造成伤害”可直接选择单位或总部、阵营、手选/随机/全部/自身、数量与区域。常用效果合并显示，可展开完整选择、筛选和逐个处理步骤。
- 多输出结果能在后续积木中引用；修复布尔 false 的存储；高级脚本支持多行正文及输入输出声明编辑。
- 自动解析支持检查、追加、替换；完整解析和原生编译均成功才保存，不完整句子不会覆盖原有效果。Inspector 可以返回当前卡牌的自动解析器。
- 修复保存窗口内容过长遮住确认按钮，以及移动积木时拆散目标选择步骤的问题。

## 更新

- Windows 页脚提供“检查更新”、下载进度、失败重试、下载完成和退出更新状态；无匹配补丁时显示完整包下载入口。
- 以往 beta.9 找不到 beta.10→beta.11 补丁时会静默跳过完整包，造成“完全没有更新提示”。本版配套发布 beta.9、beta.10、beta.11 各自到 beta.12 的精确构建补丁。
- Windows 匹配到补丁后后台下载并校验 SHA256，正常退出游戏后应用，下次打开使用新版；无匹配补丁时不擅自下载完整包。
- 检查或下载失败不会影响游戏启动，可点击重试。诊断日志位于游戏用户数据目录 `updates/update.log`。
- 安卓仅检查和提示新版，点击打开发布页；不自动下载或安装。APK 版本代码为 23。

## 使用方法

Windows beta.9/10/11：保持联网启动旧版本，等待补丁下载后正常退出，再启动；旧版检查过程中没有进度显示。也可在本发布页选择对应来源构建的 `.orcupdate`，使用“更新游戏.exe”离线应用。新玩家下载完整 ZIP，完整解压后运行 KardsUi.exe。

Android：下载 APK 并覆盖安装，保留应用数据；无需卸载旧版。已安装的旧 APK 不能凭服务器清单获得尚未内置的提示界面，需先覆盖安装本版。

## 验证与限制

- 382 项发布相关测试通过；包含更新选择、下载、校验、工坊与 Inspector 回归。
- Godot 更新流程覆盖：无匹配补丁的可见下载入口、断网重试、哈希错误拒绝、下载完成提示。
- 目标伤害已通过原生对局执行验证；完整 DIY 教程、17 个卡包编辑入口和手机比例模拟通过。
- 文字规则与积木规则分别编辑并保留；尚不支持任意文字规则逆向还原为积木。
- “下个回合开始时”“对敌方总部造成伤害后”此前报告的语法或原生适配缺口仍未解决，本版不会吞掉条件后保存为立即效果。
- 安卓 arm64 与 x86_64 打包，实体手机尚未验证。
