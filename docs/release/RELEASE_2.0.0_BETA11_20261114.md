# 2.0.0-beta.11（2026-11-14）

修复默认作战房间无法开局：自带“铜墙铁壁系列”（orc.bulwark）的三个效果仍是旧 effects/*.prefab.json，v4-only 服务端因此拒绝开局。已迁移为 v4 组件，保持卡牌与效果 ID；发行包排除旧制品，房间快照不带已退役的旧格式残留。无需删除卡组或清空应用数据。

新增全部默认自带卡包参与的房间回归（桌面独立服务端、进程内服务端）；Android 探针同样包含全部默认包。此前只用自建包的探针漏过了这条实际玩家路径。

Windows：beta.10 使用本版 .orcupdate，下载完成后退出更新，或运行更新游戏.exe手动安装。新玩家使用完整包。
Android：下载本版APK，直接覆盖安装，不要卸载或清空数据。arm64已构建，实体手机尚未验证；x86_64模拟器验证。

本版延续 beta.10 的 DIY 教程和统一积木 Inspector。
