# 2.0.0-beta.5（2026-11-07）

PC 功能发行。沿用整代版本 `2.0.0`，预发布序号从 `beta.4` 递增到 `beta.5`。

本版是一件小事加一次兑现：**工坊首页可以直接进新版 Inspector**，以及**自动更新第一次被真正跑通**
（beta.4 引入了它，本版是它第一次用自己把版本推上去）。

## 更新内容

### 工坊首页直接进「新版 Inspector · 积木编辑」

以前积木编辑只能从「效果编辑器」进，而它保存的目标是**当前打开的卡包**——从卡牌草稿那条路进去，
作者常常不知道自己搭的东西会存到哪个包。现在工坊顶部有按钮，进去就是当前卡包。

返回路径跟着出发地走：

| 从哪进去 | 点「完成」回到哪 |
| --- | --- |
| 工坊首页 | 工坊首页 |
| 旧效果编辑器 | 旧效果编辑器 |

原先写死回旧效果编辑器，从工坊进去再点完成会被弹到另一个屏，看着像迷路。
入口同时收进导航守卫：切屏前先过守卫，避免编辑中的改动被静默丢掉。

**没有打开卡包时不会直接进画布**：新版 Inspector 的保存目标是当前打开的卡包，首页没有会话，
进去只能搭、不能存——搭完点「保存到卡包」才被告知存不了，等于白干。现在会先把人带到
「我的卡包」，并写明「先打开一个卡包，再进新版 Inspector」。

从旧效果编辑器那条路进去（那里也没有会话）仍可搭、可检查，但画布**一进去就在顶部**写明
「当前没有打开的卡包，保存不可用」以及该走哪条路——不能等作者搭完才告知。

### 自动更新：全自动，不再问你要不要

以前是「弹个框问一句」，本版改成**不问**：

1. 启动时静默查一次发布页；
2. 有新版就在后台把增量补丁下下来、校验 SHA256（这一步不影响玩）；
3. **退出游戏时**交给 `更新游戏.exe` 应用，下次打开就是新版。

为什么不是「启动就替换然后自己重开」：正在跑的进程锁着自己的 dll 与 pck，替换必然失败；
而且玩家刚点开游戏就被关掉重开，体验很差。放在退出时，这一局完全不受影响。

只自动更**增量补丁**，不自动更完整包——1.2 GB 的下载不该在玩家不知情时发生。
想关掉：命令行加 `--no-update`，或在 `user://update.cfg` 里写 `[update] auto=false`。

beta.4 已经带了启动自动检查，本版是它**第一次把自己推上去**。这条链路上修掉两处只在真实环境暴露的问题：

- **更新器自己被当成游戏完整包**。发布页上每版都挂着 `OrC-KSD-offline-updater-1.2.0-win-x64.zip`，
  而完整包的正则用 `.+` 匹配版本段，于是把「更新器」当成了「游戏包」。后果是：本机 buildId
  对不上任何补丁的玩家会被引导去下 74 MB 的更新器当补丁，再交给更新器应用，必然失败，
  提示「更新没成功」——他永远猜不到是自己版本太旧。现在版本段必须长得像版本号，
  且要与该发布一致。
- **Android 不走 Windows 的补丁路径**。手机上没有「更新游戏.exe」，`.orcupdate` 对 APK 也没有意义。
  现在显式挡掉，而不是靠「没有构建清单」顺带跳过——将来若把清单打进 APK，那句
  「游戏目录里没有更新器」的提示就会跑到手机上。

## 已知问题

- **Android：本版仍然不发 APK。** beta.4 起就存在一个问题：**保留上一版的数据**覆盖安装后
  进程会在 1 秒内退出，且不写 `startup-error.txt`（说明死在托管启动路径之前）；
  `pm clear` 清空数据后同一个包能正常启动，上一版在同样的旧数据上也能启动。
  从 beta.3 覆盖安装是现有安卓玩家唯一的升级路径，所以在这条查清之前不发——
  让人装一个点开就退的包，比晚几天更糟。Android 侧仍是 `2.0.0-beta.3`。
- **单位换线的画面表现**：有反馈说单位移动到前线后位置与动画不对。本版为此加了一条
  **只看画面**的探针（`--verify-move-motion`，查「画在哪／该在哪／抬多高」，
  而不是只查投影），但目前**两条命令路径都复现不出来**：支援线 439 → 前线 267，
  抬升峰值 0.42，落定无偏差。也就是说这个现象还需要更具体的复现条件
  （连续移动、效果移动、或演出被打断），本版没有修它，只是把它变成可测的。
- **自动更新受 GitHub 匿名接口限流**（实测撞到）：发布页查询走 `api.github.com`，未登录时
  按 **IP 限 60 次/小时**。被限流时这次启动**静默跳过**检查（只写日志，不弹框、不拦启动）。
  单机每天开一次没问题；但同一个出口 IP 上开很多次、或处在运营商 NAT 后面时，
  可能整个小时都看不到更新提示。后续应改为「限流时退到 Atom 订阅只做提示」。
- 契约包的目录快照不带 `builtInOps`（引擎 issue #5）；`Check` 缺 `templateRoot`（issue #3）。

## 安装

- **Windows**：从 **beta.3 或 beta.4** 都能升。本页挂的是**兼容合集补丁**——
  一个文件里装了「beta.3 → 本版」和「beta.4 → 本版」两个变体，更新器自己按本机构建 id 挑。
  - 已在 **beta.4**：启动游戏会自动提示更新，点「现在更新」即可（自动更新会挑合集里对得上的那份）。
  - 还在 **beta.3**：下载本页补丁，用游戏目录里的 `更新游戏.exe` 手动应用。
  - 全新安装：需要完整包（约 1.2 GB），按仓库规则不挂在本页。
- **Android**：本版不发，仍是 `2.0.0-beta.3`。
