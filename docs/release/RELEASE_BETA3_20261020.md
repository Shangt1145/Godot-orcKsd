# Beta.3：DIY 模板、Inspector 与后端接入

日期：2026-10-20。显示版本：`0.0.0-beta.3`。引擎基线：`6d72eac0d30d40e870a4d881be01d7b784d7fb31`。

目标构建：`EE2A3B2040C886ADA776346130DBE613DB6E5C51D3AE9E2DA4B2CCAD16DDE34D`。

## 本次内容

- 纳入本轮工坊、卡包编辑及 Inspector 收尾代码；单位、指令、反制按卡牌类型切换 Astral 母版，字体和排布使用模板参数，提供卡图裁切与对齐工具。
- Inspector 的条件、对象、取值与动作使用组合编辑窗口；原生效果及旧简易效果进入统一编辑流程，未知字段保留，尚未准入的声明继续作为草稿。
- 卡牌编辑的效果文本解析入口调用后端 `CardTextEffectCompiler`，不将任意自然语言视为已支持语法。
- 接入当前引擎的包发现、资产快照与词条效果库；本次发版没有修改引擎源码，也没有重新设计对局界面。
- 修复工坊测试的宿主初始化：每次载入完整内置效果库，避免进程内已注册词条引用缺失预制体；恢复工坊测试门禁，并加入 Inspector 和 DIY 更新测试。

## 获取与使用

完整包：`dist/OrC-KSD-0.0.0-beta.3-win-x64.zip`。完整解压后运行 `KardsUi.exe`，保留旁边的 `.pck` 和运行库目录；玩家无需安装 Godot 或 .NET SDK。

完整包 306,049,555 字节；兼容补丁 `OrC-KSD-0.0.0-beta.3-compatible-to-EE2A3B2040C8.orcupdate` 为 19,127,717 字节，约减少 93.75% 的下载量（首次使用另需更新器 ZIP）。

已有版本可使用 `dist/` 中本次生成的 `OrC-KSD-0.0.0-beta.3-compatible-to-*.orcupdate`。首次升级应完整解压 `OrC-KSD-offline-updater-1.1.0-win-x64.zip`，运行其中的“更新游戏.exe”，选择旧游戏目录与补丁。补丁按来源构建哈希识别已收录的 Beta.1／Beta.2 版本；不支持的混装构建会停止，不能仅按显示版本号判断兼容性。

二进制按仓库约定保存在本地 `dist/`，不提交 Git。校验和见 `dist/SHA256.txt`，构建编号、大小与补丁文件名见 `dist/offline-update-report.json`。
