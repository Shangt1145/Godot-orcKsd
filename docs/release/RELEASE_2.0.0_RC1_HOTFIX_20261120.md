# OrC-KSD 2.0.0-rc1-hotfix（2026-11-20）

这是 RC.1 的预发行热修复。Windows 提供从公开 RC.1 构建升级的增量补丁，也提供完整下载。

## 训练

- 修复电脑提交选靶后提前结束回合的问题。电脑会继续使用引擎返回的动作结果。
- 对手回合结束后，演出队列清空时恢复玩家的合法移动和攻击。
- 单机训练可以在对手回合选择认输。当前动作结算后进入败北结果。

## DIY 工坊

- 新建卡牌仍需进入卡包或扩展包。新增补给步兵、火力打击、增援指令模板。
- 在卡牌页直接设置抽牌、伤害或攻防增强。练习对局可以使用草稿，试打后可回到原卡修改。
- 新教程覆盖做卡、部署抽牌和修改后再试。工坊和卡牌页均可打开说明书。
- 包内「打开 DSL」可重开已保存的积木效果，或打开独立的 `.hdsl.json`。
- 本机卡包和扩展包可从工坊移除，删除后保留备份。有依赖的基础包会提示先处理依赖。

## 安装与升级

- Windows RC.1 用户可以在线下载对应补丁，下载完退出并重新启动。其他构建可使用完整 ZIP。
- Android 安装代码为 26，包名和签名沿用 RC.1。支持 Android 7.0 及以上的 arm64-v8a 与 x86_64 系统。
- RC.1 安装时报「解析包时出现问题」的设备尚未复现，新包的签名与封装验证不能代替该设备的安装验证。
