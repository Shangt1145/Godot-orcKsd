# OrC-KSD 2.0.0-beta.13（2026-11-15）

本版将 Inspector 的触发、条件、固定取值和目标范围拆成独立积木，移除 Inspector 中的下拉框和弹出式选项菜单。

## Inspector

- 当前引擎目录的 42 种动作、104 个触发模板变体和 17 种运算符均提供积木入口。
- 触发事件使用固定帽子块，触发条件使用独立六边形积木。从工具箱放入对应积木，画布不再嵌入事件下拉框。
- 目标范围拆成 31 种独立积木，包含阵营、区域、选择/随机/全部、总部与本卡自身。数量保留数字输入。
- 比较与逻辑运算使用可嵌套的条件块；属性读取、事件字段、变量引用及固定内容使用独立取值块。
- 脚本输入输出按数值、文字、真假、实体及三种列表类型分别添加，声明中没有类型下拉框。
- 触发切换纳入撤销和重做；保存使用画布中的触发设置。重新打开保留事件、对象条件和动作。
- 修复仅填写“那么”时自动生成空“否则”分支而导致校验失败的问题。
- 保留目标伤害编辑、自动解析器和高级脚本入口。固定取值仍保存引擎原始值，界面使用中文。

## 安装与更新

Windows：新用户下载完整 ZIP，完整解压后运行 KardsUi.exe。beta.9、beta.10、beta.11、beta.12 提供各自精确构建到本版的补丁。联网启动旧版，等待补丁下载完成后正常退出，再启动新版；beta.12 会显示检查、下载和就绪状态。也可下载对应来源构建的 .orcupdate，使用随包的“更新游戏.exe”离线应用。

Android：下载同版本 APK 覆盖安装，保留应用数据，不需要卸载。安装代码递增至 24，包名和签名保持连续。安卓只检查和提示新版，点击打开发布页，不自动下载或安装。

## 验证与限制

Inspector 实际界面验证覆盖全部动作、触发与运算符入口，12 处固定取值参数的逐项替换，31 种目标范围积木，撤销/重做、嵌套分支、自动解析入口，以及教程和卡包保存重开。发布包另经独立 EXE、工坊和真实更新器升级验证。

支持范围仍以当前引擎契约为准；不会通过前端伪造尚未开放的规则。文字规则与积木规则分别编辑，尚不支持任意文字规则逆向还原为积木。“下个回合开始时”“对敌方总部造成伤害后”此前报告的语法或原生适配缺口没有在本版修复。


- 382 项发布相关测试及 4 项发布清单地址回归测试通过。
