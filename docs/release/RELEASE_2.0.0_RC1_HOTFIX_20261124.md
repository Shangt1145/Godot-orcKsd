# OrC-KSD 2.0.0-rc1-hotfix（2026-11-24 重建）

这是 RC.1 热修复线的**同一条补丁重新构建**（版本号不变，补丁起点仍是本版完整包，终点为 2026-11-24 的构建）。
老玩家走增量补丁，新玩家用完整包；两者最终字节一致。

## 卡面文本解析

- 「本单位对敌方总部造成伤害后／时」不再降级成「未实现」。它与既有的「攻击敌方总部后」是同一事件的口语异写，
  现在统一走 `afterAttackHQ`，可省略主语、可带数量词（「造成 3 点伤害后」）。
- 「下个友方／敌方回合开始时，…」整类延迟句式可以解析了：识别成 `nextTurnStart`，
  内层未声明阵营的动作跟随外层（否则「下个敌方回合开始时，我方失去 2 点」会写成反的语义）。
- 语料回归：1553 张官方卡中完整解析数 698 → 711；新增通过的卡逐张登记在复核清单里（16 → 30 条），
  每条带原文与指纹，可逐项复核。
- 仍未覆盖：「对敌方**单位**造成伤害后」（需要通用「造成伤害」监听，不是一条正则能解决）、
  「下个 X 回合**结束**时」。

## 启动自动更新

- 打开游戏就检查一次发布清单；发现适用于本机构建的补丁会**弹框**：
  显示当前版本 → 目标版本、补丁大小、以及「卡组与 DIY 卡会保留」。
- 点「立即更新」→ 带进度条下载 → SHA256 校验 → 拉起更新器并退出 → 装完**自动重开**。
- 「稍后再说」本次不更新；「跳过此版本」把该版本记进 `user://update.cfg`，之后不再提示（新版本照常提示）。
- 没有匹配补丁、或游戏目录缺更新器时仍然只给发布页入口，**不在后台擅自下载 1.2 GB 完整包**。
- 网络失败不拦启动：页脚出现「更新失败 · 点击重试」，详情记在 `user://updates/update.log`。

## 效果编辑

- 积木画布多了一个**文本视图**：同一份 handler 文档可以打印成「像代码、词是游戏词」的文本，
  也能读回成文档。认不出的写法直接报错并给行号，不做模糊猜测（保存是覆盖式的，猜错比拒绝更糟）。
