## 更新内容

### 联机

- **房间可起名**：局域网房间列表里显示的就是房主起的名字，改名不必重开房间（下一轮广播即生效）。
  留空时仍显示"好友的房间"。
- **可固定端口**：想固定就固定，并直接写明"公网联机要在路由器把 TCP 端口映射到本机；
  局域网或虚拟局域网直连不用"。固定端口被别的程序占用时**不静默换端口**，而是退回自动分配并明说原因。
- **加入失败会自己重试**：连接层瞬时故障退避重试 3 次；`拒绝连接 / 超时 / 找不到地址 / 网络不通`
  翻成人话；房间已满或已开局是明确结论，不重试，直接给「重试加入 地址:端口」。
- **「入场申请」升级为「房间成员」**：上半是待处理申请（批准/拒绝），下半是已连接的人（移除）。
  移除即断开并释放座位；**对局中移除等同于该座位认输**，确认页写明。
- **掉线重连补了两处死路**：大厅阶段断线后「重新申请入场」按钮以前永不出现；
  房主对局中掉线重连后战场以前永久冻结。两处都已修。

### 对局内

- **行动记录面板**：三个页签——战报（完整行动序列，只读）、弃牌堆（弃牌与手牌上限烧掉，两方分开）、
  词条（带参数值与携带者）。战报条目只来自引擎给的表现步骤与前端自己发起的动作，**不推断规则、不补数字**；
  上限 2000 条，超出丢最旧并写明条数。
- **回合倒计时**：我方回合可见（75 秒，最后 20 秒变色）。**超时只提示，不结束回合**——
  alpha 阶段强制超时的风险大于收益。
- 弃牌演出补齐了弃牌堆落点；对手的弃牌只显示张数，**不带牌面**。

### DIY 与卡组

- **结构化选靶**：效果编辑里的目标选择不再是自由文本，改为结构化节点（选择/过滤/空目标都有明确语义）。
- **卡包整包导出/导入**：清单 + 卡牌 + 卡图走 ZIP 往返。
- **能力目录诚实化**：检查器的动作目录与引擎实际实现对齐，并按「alpha 可用 / 预览」分区，
  写明每项编不出来的原因。**161 项不等于全部机制都能跑**。
- **存档与卡牌 ID**：卡库/卡组/工坊统一走版本判定（区分"存档比游戏新"与"格式太旧"，两种都保留原文件并说明）；
  卡牌改 ID 后卡组里的引用自动重新绑定。

### 手机

- **切后台回来会明说连接状况**：回到前台先真发一次请求确认连接，再给结论——
  正在确认 / 正在重连 / 已恢复 / 没恢复。单机对局与 3 秒以内的切出不提示（不制造噪音）。
  提示是顶部横幅，不挡操作。
- 回到前台会重新点亮 Android 前台服务（系统在后台可能回收它，而界面上看不出来）。

## 不包含（明确降级，不要理解成"支持"）

- **没有房间密码**。服务端协议没有口令字段，客户端自校验等于假安全。房间真正的门是房主逐条批准入场。
- **没有观战延迟**。不绑座的观战者是全知的（能看到双方手牌），延迟只把泄牌推后几十秒，挡不住。
- **内建词条释义只覆盖 11/19**。其余在词条页明说"引擎未提供"，不编释义。
- **战报不记资源点变化与逐张抽牌**（刻意，理由在 `BattleLog` 类注释里）。
- **手机切后台的提示没有真机验证**。桌面不发 `paused/resumed`，只在桌面探针里验过行为；
  Android 实体机仍待验。
