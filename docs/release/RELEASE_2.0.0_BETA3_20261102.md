# 2.0.0-beta.3（2026-11-02）

PC 与 Android 同步功能发行。沿用整代版本 `2.0.0`，预发布序号从 `beta.2` 递增到 `beta.3`。
本版是**诚实性修正**：把「目录里有、但现在跑不起来」的积木标出来，不再让作者以为点了就能用。
按常规版本产出 Windows 全量、增量补丁、更新器与 Android APK。

## 更新内容

- **能力分区（alpha / preview）**：契约 v1 在 11-02 新增 SPEC §12.11，要求目录对每个可拖的东西
  给出「这版真能跑」还是「目录里有、现在跑不起来」，并定了两条硬规矩——**不裁剪**（preview 照样
  出现，只影响排序与提示）、**判据是显式登记不是探针**。本版按此实现。
- **`choice` 标为预览态**。这是今天唯一的 preview：它的运行时实现 `ChooseAsync` **无条件抛**
  `NotSupportedException`（选项呈现需要前端桥接，尚未接入）。之前它被当成普通积木摆着——
  能画、能校验、能生成 csx、一跑就炸。现在：
  - 工具箱里该行**压暗 ＋ 右侧「还不能用」角标**，hover 显示原因；**仍然可点**
    （契约要求「允许先搭图，保存前再拦」）
  - 画布上的块标题后同款角标——作者是在这块积木上做决定，不能只在右栏提一句
  - 检查结果出一条金色警告「有 N 块现在还跑不起来」并逐条列出原因，右上角计数变「N 块跑不起来」
  - **没有新增错误码**：13 个码是封闭的，预览态是「能存但跑不了」的事实，不是校验错误
- 内建 op 的分区照抄契约的十项清单（`sequence`…`script`），不自行推导；节点级分区缺省 alpha、
  不写进目录快照。
- **引擎侧未改动**：本版把 11-02 引擎更新的逐项核对写成文档
  （`docs/engine/ENGINE_UPDATE_20261102.md`），引擎仓库只读使用。该更新同时带来
  **信号守卫**（成员级 `guard` 四档，可用性只由白名单决定）与**效果模板库**（按「信号 × 守卫档」
  派生 102 条），但两者都**不在 handler DSL 语法里**，与本版界面无关，只做记录。
- 顺带修正一处此前的判断错误：11-01 那次调研把 `choice` 的「运行期」判为已实现，依据是生成器
  产出了 `ChooseAsync` 调用。生成能过 ≠ 跑得起来——`ChooseAsync` 本身就是无条件抛。

## 安装与更新

- Windows 已安装 beta.2：用更新器 **1.2.0** 应用本版唯一的 beta.2 → beta.3 补丁
  （6.69 MB，相对 1.22 GB 全量省 **99.45%**；本版只动了 3 个文件）。
- Windows 新玩家：按仓库发行规则，超过 1 GB 的全量包在 `dist/releases/2.0.0-beta.3/full/`
  本地保留、不上传；需要时从本机发行目录取。
- Android：下载本版 APK 覆盖安装。`versionCode=14`，版本名 `2.0.0-beta.3`，包含
  arm64-v8a 与 x86_64。Android 走完整 APK 更新，不使用 Windows 的 `.orcupdate`。
- 源码对应标签 `v2.0.0-beta.3`。构建所用引擎提交 `169e57518763e1b80c4bae4a1b39023ad4c0b221`
  （本地 v4 分支；**未**包含 `origin/main` 上 11-01、11-02 的四个提交）。

## 验证记录

- 构建标识 `3CB83D2AE7F92A034BABD0A4BE8762506FDA6A8C34273A3A8F776595343302C8`；
  全量包 1,223,620,852 字节，补丁 6,689,053 字节，更新器 74,327,766 字节。
- 发版门禁：源码同步 → 编译 → 单元测试（工坊／DIY／卡包／构筑／离线更新等分组）→
  headless 原生 UI 验证，全部通过后导出。
- 导出后验证（在解压出来的真实包上跑，不认 Godot 退出码）：`--verify-export` 与
  `--verify-workshop` 均通过；离线更新用**真实更新器 exe** 从 beta.2 升级到本版，玩家自建
  文件保持原样，升级后 EXE 再跑一遍 `--verify-export` 通过。四份日志在
  `dist/releases/2.0.0-beta.3/verification/`。
- 单元测试全量 746 项：**744 通过 / 2 失败**。失败的两项（`CrossEffectTargetTests` 的回合结束
  效果、`MatchDebugTests` 的调试指令）在干净检出 `bac0298` 上复跑**同样失败**，与本次改动无关，
  属引擎侧漂移，未在本版修复。本版新增 3 条分区测试，其中一条断言「`choice` 是唯一预览态」——
  引擎接通 S10 后它会先红，逼人回来改分区。
- Android：`ANDROID_EXPORT_OK`，APK 726.5 MB（761,780,383 字节），含 `AndroidManifest.xml`
  与 `classes.dex`；按 alpha.5 以来的惯例出 debug 侧载包（本机无 release keystore 配置）。
- 详细核对：[11-02 引擎更新调研](../engine/ENGINE_UPDATE_20261102.md)、
  [Inspector 选型与实施 §11](../design/INSPECTOR_SELECTION_20261031.md)。

## 保留的边界

- 编辑面**仍然没有写回**：不接 `AssetEditor.Commit`，不产出 `.moding.json` 草案，卡牌草稿里的
  效果仍是原来的文本形态。这是下一版的第一件事。
- 「保存前拦住预览态」只做到**提示**，真正的阻断要等保存链路接上——现在还没有保存按钮。
- 效果模板库的 102 条模板**不在仓库里**（`ORC_WRITE_TEMPLATES=1` 才生成），所以界面上暂时
  没有「从模板新建」可做。
