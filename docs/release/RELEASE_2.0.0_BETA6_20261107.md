# 2.0.0-beta.6（2026-11-07）

PC 功能发行。沿用整代版本 `2.0.0`，预发布序号从 `beta.5` 递增到 `beta.6`。

本版把**自动更新做成真自动**，并把它从「不可靠」修成「可靠」——beta.5 里那套还留着三个会让玩家
「怎么一直没更新」的坑。

## 更新内容

### 自动更新：不问，启动下载、退出应用

以前是弹个框问「发现新版本，现在更新？」。那叫自动提醒，不叫自动更新。现在：

1. 启动时**静默**查一次；
2. 有新版就在后台把增量补丁下下来、校验 SHA256（不影响玩）；
3. **退出游戏时**交给 `更新游戏.exe` 应用，下次打开就是新版。

为什么不「启动就替换然后自己重开」：正在跑的进程锁着自己的 dll 与 pck，替换必然失败；
而且玩家刚点开游戏就被关掉重开，体验很差。放在退出时，这一局完全不受影响。

只自动更**增量补丁**，不自动更完整包——1.2 GB 的下载不该在玩家不知情时发生。
想关掉：命令行加 `--no-update`，或在 `user://update.cfg` 里写 `[update] auto=false`。

### 更新检查不再依赖 GitHub 的限流接口

原来查发布页走 `api.github.com`，未登录按**出口 IP** 限 60 次/小时。被限流时检查是**静默失败**的——
只写日志，玩家只会觉得「怎么一直没更新」。实测一小时内撞到两次；而运营商 NAT 后面的玩家
是一整个小区共用这一个额度。

现在首选**静态清单**（`releases/download/channel/latest.json`，走发布页 CDN，不吃 API 配额），
API 只当退路。清单里直接带文件名、大小和下载地址，连「先拉 SHA256.txt 再挑资产」都省了一次请求。

### 下载卡住会报错，而不是永远挂着

`HttpClient.Timeout` 在 `ResponseHeadersRead` 模式下只管到**响应头**，正文阶段没有超时。
实测下载卡在 6.5 MB 整整七分钟一个新字节都没来：游戏既不算失败也不往下走，
玩家看到的就是「更新永远没动静」。现在每次读取都设停滞闸门（45 秒没有新字节即判定连接死），
失败留给下次启动重试，绝不无限挂着。

### 工坊首页直接进「新版 Inspector · 积木编辑」

以前积木编辑只能从「效果编辑器」进，而它保存的目标是**当前打开的卡包**——从卡牌草稿那条路进去，
作者常常不知道自己搭的东西会存到哪个包。现在工坊顶部有按钮，进去就是当前卡包。

返回路径跟着出发地走：从工坊进去「完成」回工坊，从旧效果编辑器进去仍回效果编辑器。

**没有打开卡包时不会直接进画布**：新版 Inspector 的保存目标是当前打开的卡包，首页没有会话，
进去只能搭、不能存——搭完点「保存到卡包」才被告知存不了，等于白干。现在会先把人带到
「我的卡包」，并写明「先打开一个卡包，再进新版 Inspector」。

从旧效果编辑器那条路进去（那里也没有会话）仍可搭、可检查，但画布**一进去就在顶部**写明
「当前没有打开的卡包，保存不可用」以及该走哪条路。

## 已知问题

- **Android：本版仍然不发 APK。** 保留上一版数据覆盖安装后进程会在 1 秒内退出
  （`pm clear` 清空数据后同一个包能正常启动，上一版在同样的旧数据上也能启动）。
  从 beta.3 覆盖安装是现有安卓玩家唯一的升级路径，在这条查清之前不发。Android 侧仍是 `2.0.0-beta.3`。
- **单位换线的画面表现**：有反馈说单位移动到前线后位置与动画不对。为此加了只看画面的探针
  （`--verify-move-motion`：查「画在哪／该在哪／抬多高」，而不是只查投影），但目前**两条命令路径
  都复现不出来**（支援线 439 → 前线 267，抬升峰值 0.42，落定无偏差）。本版没有修它，只是把它变成可测的。
- 契约包的目录快照不带 `builtInOps`（引擎 issue #5）；`Check` 缺 `templateRoot`（issue #3）。

## 安装

- **Windows**：从 **beta.3／beta.4／beta.5** 都能升。本页挂的是**兼容合集补丁**，
  里面装了几个源构建的变体，更新器按本机构建 id 自己挑。
  - 已在 **beta.4 或 beta.5**：启动游戏会自动下载并提示，退出后生效（下次打开就是本版）。
  - 还在 **beta.3**：下载本页补丁，用游戏目录里的 `更新游戏.exe` 手动应用。
  - 全新安装：需要完整包（约 1.2 GB），按仓库规则不挂在本页。
- **Android**：本版不发，仍是 `2.0.0-beta.3`。
