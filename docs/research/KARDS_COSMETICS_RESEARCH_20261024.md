# 原版 KARDS：卡背、桌饰、表情与战场总部

调研日期：2026-10-24。用户已确定总部只改外观，并要求联机双方可见。本轮先核对原版，不将此前新写的功能草稿视为原版复刻验收，也没有重新导出发行包。

后续实施状态：已完成卡组/国家归属与联机纸质表情等调整，详见[实施与验证记录](../acceptance/COSMETICS_20261024.md)。下文“当前草稿需要改的地方”保留调研时的差异快照，不代表全部仍未实现；独立战场主题、专属物件动作和原版精确声音/动画仍待后续。

## 已确认的原版行为

### 入口与配置归属

官方帮助提供的路径是：主菜单 **Cards → 选择卡组 → 右侧 Customize → 四个分类页签**。重点是先选卡组，再配置其展示；并不是与卡组、国家无关的一套全局图片设置。官方新 UI 说明也在选中卡组的右侧提供 Customize，并在构筑概览中保留 HQ/Battlefield 编辑入口。[官方自定义指南](https://support.kards.com/hc/en-us/articles/27800786503961-Deck-Customization)、[官方新 UI 说明](https://www.kards.com/news/new-ui-coming-soon)。

| 分类 | 官方明确的保存范围 | 对本项目的含义 |
|---|---|---|
| 卡背 | 当前选中的卡组 | 同一国家的两个卡组可装备不同卡背 |
| 战场总部 / Battlefield | 当前选中的卡组 | 总部主题应跟随卡组，而非覆盖全部总部 |
| 桌饰 / Board items | 此国家的所有卡组 | 装备时须提示会影响同主国家卡组 |
| 表情 / Emotes | 此国家的所有卡组 | 按主国家管理表情配置，换不同国家应正确切换 |

该范围直接来自官方指南。官方截图可在指南中打开：[卡组右侧入口](https://support.kards.com/hc/article_attachments/27800786479257)、[四分类示意](https://support.kards.com/hc/article_attachments/27800786494105)。补充调研已下载并目视检查四分类导航及官方卡组选择页；四个分类的内部装备网格仍未取得完整截图。

## 补充：实际样式与画面证据

用户指出首轮只核对配置规则，没有充分调查表情等外观。本节依据实际打开检查的原图；截图、宣传画和运行中的动画分开记录。所有参考图保存在 `artifacts/research-cosmetics-20261024/`，不作为当前项目已完成的效果图。

### 表情入口、菜单与纸质样式

1. **对局菜单实图**：`community-emote-menu.jpg`，1180×540 的社区对局画面。右下角是浅色三点对话框小图标，其上展开深灰近黑、浅色细边框的直角菜单；菜单右下有小三角指向入口。文字浅色、左对齐，选项纵向排列，没有大幅缩略图，也不是围绕总部展开的轮盘。该图能读到八条短句，包括“漂亮的卡组”“那是个错误”“漂亮！”“你在开玩笑吗？”“zzz”“一场光荣的战斗”，最下方另有灰色“切断通讯”。**这证明该画面中有八条短句，不能据此断言所有版本的装备上限恒定为八。** 菜单覆盖桌面右侧边缘区域，没有覆盖中央总部。图片只证明这一版画面，不能证明当前桌面版的全部布局。[社区画面来源](https://www.douyin.com/video/7568982633968777851)。
2. **官方表情图标**：`official-customization-tabs.png` 的 EMOTES 分类采用做旧浅色矩形对话框、三个深色圆点、下侧短尾；其他分类使用卡背剪影、手雷、HQ 盾徽。分类按钮是暗色磨损金属面板，有边线和角铆钉，当前 CARD BACKS 文字与图标变黄橙色。[官方四分类原图](https://support.kards.com/hc/article_attachments/27800786494105)。
3. **官方纸质表情宣传画**：`official-p38-battlepass.png` 中的 “SAY HELLO TO MY LITTLE FRIEND!” 是横向浅黄旧纸条，边缘不规则并有折痕，下侧一个短尾，深色大写打字机风格文字。它与写实 P38 手枪一起放在木桌场景中。`official-tow-cardbacks-emote.png` 的三点对话框也呈旧信封纸质，能看见封口折线和邮戳。**两张均为宣传资产，不据此推断对局中的尺寸、坐标或动画。** [P38 官方公告](https://www.kards.com/news/october-2025-battlepass-preview)、[战区官网](https://www.kards.com/theaters-of-war)。
4. **中文特殊表情商品预览**：`community-emote-art.webp` 的商店截图中，“干嘛阴沉着脸？”显示为浅色纸片加红色粗体文字，下侧带尾；商品说明明确写每个国家的表情可在自定义界面更改，并标注该表情适用于所有国家。说明“按国家装备”和“一个表情可供多国使用”可以同时成立。该截图不是对局气泡，红字也不能推广为全部普通表情的统一字色。[社区截图及原帖](https://www.233leyuan.com/post-detail/2065471783338176512)。

因此当前草稿应先纠正文字“表情”按钮和大块圆角聊天面板的视觉方向：采用原版的三点对话框入口、边缘纵向菜单，以及符合桌面材质的紧凑纸条表达。**后一句是实现方向；发送后具体出现位置、尾巴朝向、是否旋转、渐入渐出时长及声音，仍需可播放的对局录像或原版实机。** 目前没有证据支持统一弹出“大图在上、文本在下”的聊天卡，也没有证据支持草稿的 2.6 秒寿命和六槽上限。

### 卡背：磨损纸牌及清晰的主图案

已目视检查 `official-deck-customize-entry.png`：卡背预览竖向排列成三列，整体有浅米色纸牌外缘、内侧细边框，中心为军徽、王冠、鹰徽、几何标志等；底色低饱和，表面有划痕、污渍、折损。图案的主体留在牌背中部，边框保持完整，不是把任意图片无边距铺满。卡背下有卡组名和两国标识；右侧选中卡组有独立卡背预览及 CUSTOMIZE 按钮。`official-tow-cardbacks-emote.png` 则展示五种地图和罗盘主题卡背，证明图案可以多样，但仍保持旧纸材质和统一牌形。[官方卡组选择页原图](https://www.datocms-assets.com/120590/1709892039-0e9f4b95-66e2-420c-a436-430852c41c98_3_decks.png)、[战区官网](https://www.kards.com/theaters-of-war)。

本项目验收需要同时看卡组预览、桌面牌堆、对方扇形手牌、抽牌飞行动画中的同一卡背；不能只在装备页放一张图片就算完成。

### 桌饰：真实物件的轮廓、材质与摆放

`official-p38-battlepass.png` 的 P38 有斜向摆放、金属枪身、木质握把、透视、投影；它的轮廓和卡牌矩形明显不同。这张宣传画只能证明外观设计，不提供实机缩放和交互动作。`community-emote-menu.jpg` 的战场边缘能看到斜放的刀具及散落弹药，保留中央卡牌区域；无法只凭静帧判断哪些属于背景、默认摆设或可装备物件，不把它们全部登记成可点击桌饰。结合前文官方可交互物件说明，草稿固定 112×112 的方块显示仍需调整为保持透明轮廓与比例、支持资源各自的尺寸及锚点。

### 总部与战场：保持规则层，核对完整组合

`community-emote-menu.jpg` 的双方 TRUK 总部仍是紧凑竖牌：顶部地名、中部国家图案、下部盾形防御值；该图的受损己方总部防御数值为红色，敌方为浅色。外观不能遮住名称和防御盾徽，也不能因为换图改变卡牌命中区域。

另外查看了社区整理的 `community-hq-tunis-preview.png`。虽然文件名含 `board-render-tunis`，实际只有沙土地面材质和四周暗角，没有总部卡片或桌饰。这尤其说明**不能按资源文件名把背景图误当总部卡面**；总部、桌面/桌布、边缘物件需要分别识别，再核对组合预览。社区目录自述有独立总部和桌布分类，但它不是官方规格，条目数量和名称不作为产品约束。[社区来源目录](https://github.com/Gary-nope/KARDS-Assets/tree/main/kards-profile-cosmetics-zh-Hans)。

### 本次仍未完成的动态观察

已找到主国家表情展示视频和通票物件实机演示，但当前工具分别遇到视频站 412 及页面无法读取，没有取得可播放的录像，因此没有听到声音，也没有逐帧测量。线索保留：[主国家表情、卡背展示](https://www.bilibili.com/video/BV1s2w6eDETH/)、[表情与打火机实机演示](https://www.douyin.com/video/7691767158099830130)。它们是待核实来源，不能写成已观看。

下一步仍需补：普通/特殊表情发送后的双侧位置与遮挡、连续发送和切断通讯后的反馈；桌饰点击/悬停动作及其对手端表现；更换总部后桌面哪些元素一起变化。原版精确字体文件、音频、冷却和动效参数均不从静态图片反推。

### 桌饰是战场物件，部分具有交互

官方 2025 年 10 月通行证明确将德国 Walther P38 桌饰称为可交互物件；更早的 Escalation 更新提供可交互的 Silver Dollar Lighter，Behind Enemy Lines 则提供可交互的 Molotov Cocktail。因此，“全部桌饰固定成一个不接收输入的方形 PNG”只能作为资源占位，不代表原版的完整桌饰表现。不能由这几款样例反推所有桌饰都使用相同动画或交互。[P38 公告](https://www.kards.com/news/october-2025-battlepass-preview)、[打火机公告](https://www.kards.com/news/escalation)、[燃烧瓶公告](https://www.kards.com/ja/news/behind_enemy_lines)。

官方还曾修复重连后桌饰显示的问题，说明恢复对局时也应恢复正确装备。[Global Conflict 更新](https://www.kards.com/en/news/global-conflict)。

### 总部应按战场外观资源组织

官方将部分商品描述为新的“HQ and battlefield”，而不只是任意替换总部卡片的一张图片。建议本项目将总部美术与可选战场主题组织为外观资源组合；**这是一项实现建议，不是“每个总部都必须换整张桌面”的已证实规则**。用户限定的纯外观范围仍然有效：不修改防御、效果或胜负条件。[Behind Enemy Lines](https://www.kards.com/ja/news/behind_enemy_lines)、[Global Conflict](https://www.kards.com/en/news/global-conflict)。

### 表情要有通讯状态，且终局仍可交流

官方 Ring of Fire 修复说明明确提到：切断通讯后，双方表情不再显示。实现不能只有发送按钮和冷却，必须有可见的通讯开关，并检查切断后双方表情的表现。该表述尚不足以确认“本端隐藏两侧”与“房间双端都被切断”的精确作用域，应再用原版双端验证。[官方 Ring of Fire 修复说明](https://www.kards.com/en/news/ring-of-fire-overview-and-patch-notes)。

官方战斗 UI 更新还说明，终局后玩家可以暂留棋盘、查看最终状态，并发送最后的表情；不应将终局表情误当成非法战斗命令。[官方战斗 UI 更新](https://www.kards.com/news/spring-release-battle-ui-enhancements)。

原版说明的内容获取方式是国家进度、商店及限时活动，操作围绕已获得物品的选择与装备。本项目的文件导入、自编表情文字、总部重命名可以保留为 DIY 扩展，但需要明确它们是本项目能力，不能据此代替原版的展示与配置结构。[官方自定义指南](https://support.kards.com/hc/en-us/articles/27800786503961-Deck-Customization)。

## 当前草稿需要改的地方

| 当前草稿 | 问题 | 调整方向（尚未实施） |
|---|---|---|
| 侧栏单独“外观装扮”，统一全局资料 | 没有体现卡组及国家归属 | 从卡组库/准备页的选中卡组进入，带入卡组和主国家上下文 |
| 一个 `CosmeticProfile` 持久保存所有四类装备 | 同国家多卡组无法独立换卡背与总部；换国家也沿用表情 | 卡背、总部按 DeckId 存；桌饰、表情按 MainNation 存 |
| 桌饰固定 112×112、完全不接收输入 | 缺少原版可交互物件的表现 | 资源区分图像、可选帧动画/交互；确定合法摆放区，不能截获卡牌操作 |
| 任意图片加名称就是总部 | 不足以表达 HQ / Battlefield 外观组合 | 增加总部主题描述，规则数据仍由引擎提供 |
| 表情只有文本/图片菜单与 2 秒限频 | 没有切断通讯；当前槽数和布局无原版依据 | 补通讯状态，重新核实原版入口、槽位、显示位置与节奏 |

现有联机传图、内容哈希缓存、按批准座位发送和重连恢复可以保留为传输基础，但它们只证明同步链路可运行，不证明界面或装备语义已对齐原版。

建议的新数据关系为：

```text
卡组 DeckId → 卡背、总部/战场主题
主国家 MainNation → 桌饰、已装备表情
进入对局 → 解析上述配置，生成双方可见的展示快照
```

联机仍传解析后的展示快照，不把卡组私有内容发给对方，也不往规则卡定义中写外观字段。

## 尚未核实，不应硬编码为原版事实

- 桌饰到底有几个槽、如何定位、每种物件具体的点击/悬停行为。
- 当前客户端是否延续已见截图的右下纵向菜单；最大可装备数量、精确冷却与显示时长、是否带声音，以及发送后的实际位置与动效。
- 总部主题更换时，具体哪些背景、前线或边角元素一起变化。
- 任一方切断通讯后，两个客户端各自还能看到哪些表情。
- 对手的所有桌饰局部动作是否也同步，还是仅共享装备与部分动作。

本轮依据官方帮助、官方公告、已下载目视检查的官方图片，以及注明来源的社区客户端截图；没有直接操作正在运行的原版客户端。内置浏览器截图读取失败后，已通过公开原图补充静态视觉检查，但没有完成实机逐帧调研。论坛旧版路径、其他游戏的六槽表情轮盘和未经画面检查的社区素材库不能替代以上证据。
