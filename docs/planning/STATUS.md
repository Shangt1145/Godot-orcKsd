# 项目现状（2026-10-25）

## 当前交付

- 游戏版本：**2.0.0-alpha.5**，PC 与 Android 同步功能发行；Android 安装版本号为 **10**。
- 发行入口：[v2.0.0-alpha.5](https://github.com/Shangt1145/Godot-orcKsd/releases/tag/v2.0.0-alpha.5)。
- Windows 已产出完整包与唯一的 alpha.2 → alpha.5 增量补丁。主基线为公开发布的 `72971A0DECD1…`，目标构建 `E78E6CD6D59B…`；补丁约 49.4 MiB。
- Android 已产出签名 APK，包含 arm64-v8a / x86_64；使用完整 APK 更新。
- 更新器独立保持 **1.2.0**。按规则，超过 1 GB 的 Windows 完整包保留在本机发行目录，GitHub 分发增量、更新器、APK、说明和校验和。
- 引擎公开基线 `a0b3511…` 加 [alpha.5 累计补丁](../engine-patches/alpha5-engine-20261025.patch) 可还原本轮配套源码，不重复叠加历史补丁。

## 已完成并验证

1. 图形化调试台：对局状态、卡牌实时属性、原生效果/钩子与属性修饰检查；本地调试支持双方抽牌、资源、生成/召唤、伤害/回复、属性设值、沉默/消灭及回合/自动对手控制。联机和回放只读。
2. 部署的落点与目标独立保留；空位部署后继续选靶；取消不扣费、不部署、不产生半截效果。动态生成卡牌也接入预打出。
3. 保留跨段“其”的目标复用、原生卡包/扩展包和可编译 DIY 卡联机同步，以及 Android 完整解析器、内置房间和系统文件能力。
4. 客户端 626 项、原生引擎 1360 项测试通过；12 个界面、521 张卡池检查通过。Windows 导出、工坊、真实更新器及升级后程序通过。
5. 最终 APK 已在 Android 35 x86_64 模拟器安装，图形调试与三条部署输入流程、文档/图片读写、编译、训练、开房同步、联机效果及回放验证通过。ARM64 已打包，尚无实体手机实测。

## 保留事项

- 检查器的 161 项动作目录不等于全部机制已可执行；无法无损编译的声明继续保留为草稿，并显示原因。
- 本轮未全量重生成官方卡池，旧生成物及自动解析覆盖仍需逐项扩展。
- 下一步优先做 ARM64 实体机验证与复杂 DIY 机制覆盖，不能用模拟器或卡图存在代替规则验收。
