## 二、今天定下的规矩（都已机器化）

1. **一版一补丁**：改版本号前，同一版本号下只有一条热修复补丁；新修复=重出并覆盖同一条。
2. **热修复只发补丁**，不发全量包；tag 与 Release 照建。
3. **发版八步**：干净 → 改版本号 → 出包 → **提交** → 打 tag → push → Release → 核对。
4. **一次只开一个改代码的窗口**；收工前 `git status` 必须为 0。
