# Inspector 积木覆盖

本次将触发事件、触发对象条件和表达式纳入现有积木画布。动作目录、触发模板和可读属性仍从当前引擎契约读取；前端不增加规则，也不把未开放的能力标为可执行。

- 动作工具箱使用可点击的动作积木；当前扫描目录包含 42 种动作。
- 触发事件分类展示全部 104 个模板变体。画布的帽子及条件块只显示已放入的固定内容，不含选项控件；通过工具箱中的独立事件、条件积木替换，并且只接受当前事件允许的模板组合。
- 取值与运算分类展示 17 种算子、当前事件字段及合法可读属性。数值和实体使用圆角取值块，真假结果使用六边形条件块，表达式参数可递归编辑。
- 参数编辑使用独立积木列表，保留已有绑定、合法属性、事件字段、固定取值和常量入口。数字和文字继续作为块内参数输入。固定内容通过放入或替换积木实现，没有下拉框或弹出式选项菜单。
- 目标范围拆成 31 种独立积木：双方阵营、三种区域与选择/随机/全部的组合，以及三种总部范围和本卡自身。数量是独立数字输入，改变数量不会改动目标规则。
- 脚本声明按数值、文字、真假、实体及三种列表类型，分别提供输入、输出添加积木。声明的类型在添加时确定，不在声明块里放类型选项。
- 工具箱分类使用直接可见的分类按钮，保存时的替换目标使用逐项可见的积木列表。Inspector 不再创建 OptionButton 或 PopupMenu。
- 触发模板纳入撤销和重做历史，并同步可读写的事件字段。保存只读取画布的触发模板，保存窗口不再另设一套触发选择。
- 修复绘制条件块时自动创建空的“否则”分支的问题；只选择插入位置不会改写文档，实际插入动作后才建立可选分支。
- 保留目标伤害组合、自动解析器和高级脚本入口。新插入的空条件分支仍须补入动作，校验会明确提示。

## 验证入口

`--verify-diy-capabilities` 增加对动作/触发/运算目录积木覆盖、实际点击触发切换、撤销重做、嵌套条件、取值积木选择及真假参数类型的验证。新增逐项检查当前 12 处固定取值参数，验证每个候选是独立积木，点击后保持引擎原值，并检查画布和弹窗中没有选项控件。

`--verify-diy-tutorial` 验证实际教程入口、部署事件与本单位条件的保存和重开，以及返回卡牌编辑。

`--verify-native-workshop` 验证卡包保存窗口沿用画布触发，及原生工坊保存和替换路径。

此变更为源码和开发运行副本更新，未变更 beta.12 的公开发布包。

相关 .NET 回归测试共 157 项通过。Godot 实际界面验证的日志位于本地 artifacts/inspector-blocks-*.log 和 artifacts/inspector-fixed-blocks-*.log，截图位于开发运行副本 artifacts/inspector-blocks/。
