# Inspector 积木覆盖

本次将触发事件、触发对象条件和表达式纳入现有积木画布。动作目录、触发模板和可读属性仍从当前引擎契约读取；前端不增加规则，也不把未开放的能力标为可执行。

- 动作工具箱使用可点击的动作积木；当前扫描目录包含 42 种动作。
- 触发事件分类展示全部 104 个模板变体。画布顶部的帽子积木编辑事件，内部六边形积木编辑对象条件；条件只列当前事件允许的模板组合。
- 取值与运算分类展示 17 种算子、当前事件字段及合法可读属性。数值和实体使用圆角取值块，真假结果使用六边形条件块，表达式参数可递归编辑。
- 参数编辑弹窗使用积木列表，保留已有绑定、合法属性、事件字段、枚举和常量入口。数字和文字继续作为块内参数输入。
- 触发模板纳入撤销和重做历史，并同步可读写的事件字段。保存只读取画布的触发模板，保存窗口不再另设一套触发选择。
- 修复绘制条件块时自动创建空的“否则”分支的问题；只选择插入位置不会改写文档，实际插入动作后才建立可选分支。
- 保留目标伤害组合、自动解析器和高级脚本入口。新插入的空条件分支仍须补入动作，校验会明确提示。

## 验证入口

`--verify-diy-capabilities` 增加对动作/触发/运算目录积木覆盖、实际点击触发切换、撤销重做、嵌套条件、取值积木选择及真假参数类型的验证。

`--verify-diy-tutorial` 验证实际教程入口、部署事件与本单位条件的保存和重开，以及返回卡牌编辑。

`--verify-native-workshop` 验证卡包保存窗口沿用画布触发，及原生工坊保存和替换路径。

此变更为源码和开发运行副本更新，未变更 beta.12 的公开发布包。
