# KARDS 主菜单与对局外界面参考

日期：2026-10-11。对应客户端：A.21。

用户明确本轮是主界面、卡组、收藏等对局外界面。研究对象是官方发布的客户端截图和说明，不是 KARDS 网站自身的网页布局；没有启动原版客户端，也不把历史截图当作当前版本的逐像素标准。

## 参考与观察

1. [官方新 UI 总览（2023）](https://www.kards.com/news/new-ui-coming-soon)及[官方 Steam 公告](https://store.steampowered.com/news/posts/?appids=544810&enddate=1678187811&feed=steam_community_announcements)：主界面分为顶栏、左侧主要入口、中间内容展示、右侧快捷入口和下方进度。Cards 下包含卡组库、构筑及收藏；选卡组时，中央是可滚动封面网格，右侧是所选卡组与开始按钮。构筑保留中央卡池和右侧卡组列表。
2. [官方新 UI 发布说明](https://www.kards.com/news/new-user-interface)：在浏览器中实际查看了[主菜单布局图](https://www.datocms-assets.com/120590/1709841279-f6541f4e-f470-41f9-9f13-931e75f284a1_1_main-menu.png)和[卡组选择图](https://www.datocms-assets.com/120590/1709892039-0e9f4b95-66e2-420c-a436-430852c41c98_3_decks.png)。木桌／旧纸背景、暗色矩形面板、卡背封面和暖金色选中状态构成统一视觉语言。
3. [官方玩家头像介绍（2025）](https://decks.kards.com/news/united-front-player-portraits-coming-soon)：实际查看[主菜单截图](https://www.datocms-assets.com/120590/1741383808-home-screen-portrait_sc.png)，仍保留左侧 Play／Cards／Shop、中央大幅卡牌展示和右侧快捷入口。说明此信息层级并非仅见于 2023 年设计稿。
4. [官方卡组自定义说明](https://support.kards.com/hc/en-us/articles/27800786503961-Deck-Customization)：主界面的 Cards 进入卡组页面；选中卡组后，操作集中在右侧。
5. [官方收藏与造卡说明](https://support.kards.com/hc/en-us/articles/27799746557337-Wildcards-and-Creating-Cards)：Cards 下通过顶部 Collection 进入收藏；搜索、筛选和查看卡牌详情具有明确入口。

## 本项目采用的方案

| 原版结构 | A.21 的落地 |
|---|---|
| 左侧少量主要入口 | 开始、卡牌、DIY 工坊；顶栏品牌回主菜单，右侧帮助和设置 |
| Cards 内部导航 | 我的卡组、收藏、构筑共用顶部二级导航 |
| 大幅内容展示 | 复用本地纸地图及卡背，由 Godot 原生绘制路线和卡牌展开；不新增外部位图依赖 |
| 右侧主要操作 | 首页显示当前对战卡组及开始按钮；卡组库显示正在查看的卡组与对应操作 |
| 卡组封面网格 | 可滚动封面列表、新建卡组空位；查看状态和实际启用状态分开 |
| 收藏搜索和筛选 | 搜索与数量放在顶部，筛选可展开并标记已应用条件数，详情保留在右侧 |
| 桌面质感与暖色强调 | 复用现有桌面，单独为菜单设置军绿／旧纸色主题，主操作采用橙色 |

原版的金币、钻石、通配卡、商城、好友、任务、国家进度和联网 PvP 需要对应数据与服务，本轮没有为它们添加占位入口或虚构数值。底部呈现实际保存卡组、收藏、自定义卡牌数量；现有玩法是与自动对手对战。

国别封面使用项目实际主国标识（例如 av76），不冒充原版国家身份。构筑和 DIY 编辑页隐藏左侧栏以保留编辑空间；顶部品牌仍可返回主菜单。对战继续使用自己的主题，菜单主题不改变战场资源、卡面、指令和部署演出。

## 操作边界

默认启动停留在主菜单，不会自动开启对局。开始入口先选卡组；首页的当前卡组按钮可直接开始。点击封面仅改变正在查看的卡组，明确启用或开始时才改变对战卡组。草稿可编辑但不能启动；验证沿用现有桥接服务，不增加前端游戏规则。

返回主菜单保留当前对局；左侧“返回战场”恢复同一实例，仍遵循现有回合和选择限制。Esc 在主菜单、卡组库、收藏、帮助及设置返回首页，不接管战场、构筑或 DIY 编辑器的键盘事件。
