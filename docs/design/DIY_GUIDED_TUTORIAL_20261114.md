# DIY 工坊引导教程

入口：游戏侧栏「DIY 工坊」→ 顶部「DIY 引导教程」。

第一课制作「补给步兵」：2 费、2 攻、3 防、行动费用 1，步兵单位，闪击，部署时自己抽 1 张牌。开始按钮创建独立练习卡包及空白卡牌，使用当前启用的基础卡包作为依赖。

## 玩家流程

1. 属性：填写名称、类型、兵种及四个数值，国家任选。
2. 词条：在规则页勾选闪击。
3. 效果：打开「编辑效果 · 积木 Inspector…」→ 添加积木效果，选择部署时（本单位）Self 模板，添加抽牌积木，数量为 1，保存到卡包后完成返回。
4. 说明：填写「闪击。部署：抽 1 张牌。」；教程明确区分卡面说明与可执行规则。
5. 草稿：重新检查所有前置条件，实际保存，并检查原生预览准入。
6. 应用：调用原有卡包转正流程；成功后才展示完成状态。

教程面板显示当前任务、上一步、检查并继续、定位操作区域、暂时退出和从头练习。定位返回指定练习卡牌并切换到对应页签。退出及定位沿用未保存修改保护。从头练习会另建卡包，旧练习保留。

教程记录保存在 `user://diy-tutorial.cfg`，包含练习卡包、卡牌及步骤。卡牌数据使用工坊原有草稿恢复机制。重新进入第六步时退回保存检查，以便核实恢复后的内容。练习卡包或卡牌被删除时保留错误提示，允许从头新建练习。

## 实现及验证

- `DiyWorkshopScreen.Tutorial.cs`：教程状态、面板、进度及导航。
- `DiyTutorialLesson.cs`：属性、词条及积木部署抽一张牌的检查。
- `DiyWorkshopScreen.NativeWorkspace.cs`：连接当前表单、保存、卡池准入和应用成功事件。
- `DiyTutorialTests`：6 项测试，覆盖错误时机、守卫、数量、空画布、额外动作及积木保存往返。
- `--verify-diy-tutorial`：完整原生工坊 UI 流程，包括未完成时阻止前进、积木效果保存与自动关联、连续重开保存、退出续做、应用、真实试打与旧草稿工作副本。
- `--capture-diy-tutorial`：执行同一流程并在 `artifacts/diy-tutorial` 输出桌面截图。

验证模式使用独立工坊目录及教程进度文件。此课覆盖入门制作与卡包应用；复杂积木组合、卡图导入、卡组构筑和对局操作仍使用原功能，未加入本课。
