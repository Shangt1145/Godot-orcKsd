# DIY 工坊入门

在游戏侧栏打开「DIY 工坊」。点顶部「DIY 引导教程」可以跟着做卡，点「说明书」可以按问题查阅。编辑卡牌时，右上方的「？」也能打开说明书。

## 做一张卡

1. 创建或打开卡包。如果想在已有卡包上扩充内容，选择基础卡包并创建扩展包。
2. 在打开的包里点「新建卡牌」。也可点「从模板新建」，选补给步兵、火力打击或增援指令。模板会生成一张可独立编辑的新卡。
3. 填名称和数值。看一眼卡面预览，再进入「词条与效果」。
4. 点「添加效果」，选抽牌、伤害敌方单位或增强友方单位，再填数值。单位在自己部署时触发，指令在自己打出时触发。点效果旁的「编辑」可以回来修参数。复杂效果和反制可以在积木编辑器里搭建。
5. 点「试打这张卡」。游戏会保存现在的草稿，把这张卡放入练习对局的起手，并准备练习目标。试完点「返回改卡」，回到原来的卡牌页。
6. 要让构筑或新对局使用这个版本，在卡包内点「应用修改」。要分享草稿，在包内点「导出草稿」。

## 删除卡包或扩展包

在工坊首页找到对应的包，打开「管理 / 分享」，选择「删除卡包」或「删除扩展包」。尚未应用的新草稿也可以在其「继续未完成的草稿」旁删除。确认后会将包和草稿移到本机备份，工坊会显示备份路径。仍有扩展包或草稿依赖的基础包需要先处理依赖。已有卡组的记录会保留，缺少卡牌的卡组需要调整后才能出战。

## 跟着教程试两次

教程会先建一个练习卡包，然后在包里创建补给步兵。设置 2 费、2 攻、3 防、1 行动费和闪击，添加「部署：抽 1 张牌」。试打确认效果后返回，把数量改成 2，再试打一次。教程检查实际抽牌数量，完成后练习卡仍留在草稿中。

点「暂时退出」可以暂停。在工坊重新打开教程，会回到练习卡及当前步骤。点「从头练习」会另建练习包，之前的作品在工坊仍可找到。旧版未完成的课程从新版第一步开始，原练习包可以单独打开。

## 接着编辑 DSL

在打开的卡包或扩展包里点「打开 DSL」。选择包内已有的积木效果，可以恢复动作和保存时的触发时机。也可以打开独立的 `.hdsl.json` 文件。如果文件只保存了动作，先在编辑器里确认正确的触发时机，再保存到当前卡包。

## 效果没有触发时

先看「词条与效果」里有没有这条对局效果。仅填写卡面文字不会产生对局行为。然后确认卡已经部署或打出，目标也符合该效果的条件。如果用了文字解析，查看解析提示里哪一句未识别。用于联机时，确认双方使用同一版卡包。
