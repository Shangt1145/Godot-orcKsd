# 内置及随附卡包的工坊修改

修改入口现合并太空战争、引擎内置基础包、全部随附扩展包和用户工坊包；本地已修改的包只显示一次。卡牌式封面使用实际卡图和数量。原始包内的所有卡牌均可从编辑器列表或卡池卡面载入，不再只显示已保存的 DIY 卡。

修改以本机覆盖保存，保留原包与卡牌编号，旧卡组引用不变。存储使用稳定的 DIY 草稿编号并记录 SourceCardId，图鉴、构筑和原生对局使用 RuntimeId。复制或导入卡牌时解除覆盖身份，避免副本覆盖原卡。原始数据资产不写入；“恢复原版”移除单张卡的本地覆盖。内置扩展包的原生依赖仍由引擎清单决定；工坊包的基础包可调整。

原始结构效果和词条参数载入草稿；显式空结构不会误用显示文字重新解析。原本不在简单编辑面内的语义字段保留并产生明确准入诊断，未完整适配的声明不冒充可执行效果。校验通过的修改才进入原生执行；不支持的完整效果声明仍可保存为待完善草稿。此功能不等于新增了所有规则机制的引擎适配。

原生装配按原编号替换定义，同时屏蔽被替换卡的原效果和旧选靶计划，防止旧、新效果重复执行。效果执行仍通过现有桥接及引擎。已修改卡牌在编辑器、卡池、图鉴及构筑里重绘真实名称与数值，并沿用原插画。没有修改 BattleScreen、BattleCard 或对局布局。
