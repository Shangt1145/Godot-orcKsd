## 操作

进入 DIY 工坊，选择“卡包”或“扩展包”。选择卡牌会播放抉择动画，然后选择创建或修改；减弱动态效果设置生效。

创建卡包时填写名称，进入“创建词条 / 创建卡牌 / 卡池预览”。词条必须填写可执行效果，或通过效果结构编辑器配置，再校验保存。它们会注册为 OrC-KSD 原生词条组件，在真实对局执行。说明文字用于记录含义，不能代替效果实现。

创建扩展包必须先选基础卡包，再进入“创建卡牌 / 卡池预览”。扩展包继承基础包的国家和词条，可增加自己的国家和卡牌；构筑时选择父卡包即可包含扩展内容。修改入口恢复已保存的名称、基础包与对应卡牌。

创建卡牌时通过“创建 / 修改国家”填写国家名、颜色，并从本机导入图标。图标保持比例并居中显示，国家 ID 参与原生引擎的阵营与构筑规则。

## 完整卡面导入

导入类型支持自动判断、纯插画、完整卡面。自动判断以纵横比识别纵向卡面；其他布局可手动切换类型。

完整卡面会查找图像与文字区域的横向边界，裁出插画内部，去除旧卡框及数值装饰区域，再由 Godot 重绘当前卡框、国家图标和编辑字段。保留原始图片，可调整插画左边、上边、宽度和高度百分比并应用预览。不同游戏和特殊卡面布局可能需要调整裁切；这不是任意版式的无损图层分离。数值和规则文字不从图片 OCR，仍在编辑字段中填写或解析。

所有编辑数据保存在原有 user:// 下：diy-packs.json、diy-cards.json 与 art/。旧版没有卡包归属的 DIY 卡自动迁入“我的 DIY 卡包”。完整卡面原图和裁后插画分别保存，离线增量更新继续保留这些数据。
