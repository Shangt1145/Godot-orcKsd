# DIY 工作区重做（2026-11-14）

## 范围

重做工坊首页、原生与旧草稿卡牌编辑、积木 Inspector。源码版本仍为 beta.11，当前 GitHub 已发布的安装包不变；此改动等待后续打包。

## 作品库

- 移除“卡包/扩展包 → 创建/修改 → 选包 → 确认”的抉择卡导航及动画实现。
- 首页列出卡包，提供搜索、全部/我的制作/自带卡包筛选；打开按钮直接进入卡包。
- 创建卡包只需命名；扩展包另选基础卡包。名称与基础包未填写时不能提交，创建错误留在表单内。
- 导入、教程放在左侧创作区。每个卡包有管理/分享入口，保留 ZIP 导出、启用/停用、草稿放弃与诊断。
- 展示未应用或停用状态，未完成的新卡包草稿可继续制作。

## 卡牌编辑

- 原生卡与旧 DIY 草稿统一为左侧分区、中间表单、右侧实时卡面的布局。
- 原生四个分区为基础属性、词条与效果、卡图与外观、卡牌描述。旧草稿保留对应分区及原有保存与迁移语义。
- 右侧卡面独立滚动，保存草稿、应用修改、应用并构筑/试打保持原有引擎路径。
- 原生卡牌效果编辑按钮移到效果页顶部，避免被包内复用效果列表淹没。
- 保留未保存保护、原卡编号、既有效果、导入字段、自定义国家、异画与卡图裁切；所有效果编辑仍路由到积木 Inspector。

## 积木 Inspector

- 顶部区分文档操作和“当什么发生时”的触发时机选择。
- 左侧工具箱增加分类筛选，保留搜索、全部节点、预览节点提示与插入位置。
- 中间扩展执行顺序画布，放大积木标题、必填字段、输入按钮及移动操作。
- 可选输入、结果命名收进附加设置；已有可选值自动展开。展开/收起不改变文档。
- 右侧专注问题检查与保存指引，源 JSON 改为按需打开的只读窗口。
- 统一深绿与黄铜配色，减少独立蓝色面板与常驻代码。

## Inspector 能力恢复（2026-11-15）

- 以运行时引擎扫描目录逐项核对，当前 42 个节点（32 个扫描动作、10 个内置控制节点）全部进入工具箱。测试核对节点集合、全部输入输出名称及枚举值的中文显示，禁止静默退回快照目录。
- 补齐此前缺失的 attackByEffect、attackCandidates、exchange 中文词汇；布尔值提供“是/否”，修复 false 被写成数字 0 的问题。单输出和多输出变量都能进入后续积木的可用值菜单；中文结果名称在界面显示中文，保存时转成合法标识符。
- 新增实体目标选择器：上下文实体、已有实体变量、手选/随机/全部/自身、敌方/友方/双方、数量、前线/支援阵线及总部。常用动作以单张积木显示目标条件，展开后可编辑完整引擎选择、筛选、逐个处理步骤。展开/收起不改文档；移动和删除保持生成步骤完整。
- 高级脚本提供多行正文编辑，以及中文类型选择的输入/输出声明编辑；保留未修改声明的附加字段。代码正文是用户编写的引擎脚本，界面不替代引擎编译或裁定。
- 原生卡牌“词条与效果”恢复自动解析，支持自动检查、追加、替换。完整解析和原生编译均成功才原子写入草稿；不完整句子不写入。积木引用、导入效果与未知组件字段保留。
- Inspector 顶部提供“自动解析器”返回当前卡牌；保存对话框使用中文效果名称和触发时机，把内部标识放到高级设置。长表单在窗口内滚动，保存按钮保持可见。

### 验证与边界

- 前端 Handler DSL、Inspector 能力与 NativeWorkshop 测试：130 项通过。包括手选具体单位后真实扣除 1 点防御、敌方总部真实受到 3 点伤害、解析追加/替换、失败时全部文件不变、未知字段保留。
