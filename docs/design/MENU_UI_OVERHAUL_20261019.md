# 对局外 UI 改版 · 2026-10-19

## 范围

本轮更新首页、全局菜单、收藏、卡组库与构筑、DIY 工坊、卡牌编辑、效果搭建和设置。首页直接使用当前卡组进入对局，准备页退出主要流程。

对局界面保留原样。本轮尝试过的战场背景、地图分区、总部和单位卡面、指挥点及回合按钮改动均已撤回。没有改变规则引擎。

## 样式隔离

- 新增 `proto/ui/components/MenuStyles.cs`，菜单使用独立配色、主题与控件方法。
- 原 `UiStyles.cs`、`BattleCard.cs`、`KreditsDisplay.cs` 与任务开始时一致；`git diff --quiet` 对这些文件返回 0。
- `BattleScreen.cs` 仅保留任务开始前已有的手牌投影、箭头拖拽修改，本轮新增的视觉修改已逐项撤回。
- `Main.cs` 仍给对局显式指定原 `UiStyles.CreateTheme()`。对局全屏布局不出现菜单侧栏。

## 页面变化

- 固定侧栏替代顶部等权按钮；主入口、继续对局和设置工具分区。
- 首页集中显示当前卡组、就绪状态与开始操作，使用实际卡组卡面展开图。
- 收藏以卡包封面与卡牌数量组织入口；进入卡包后提供搜索与筛选。
- 卡组库突出选中状态及准备状态；构筑区统一检索、过滤和卡组面板。网格按实际可用宽度计算列数，避免从全屏对局返回后撑出窗口。
- 工坊入口、卡牌编辑和效果搭建使用统一的分区、输入框和保存按钮。
- 设置拆为演出与声音两栏。
