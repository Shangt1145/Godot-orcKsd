# DIY 卡图预览对齐修复（2026-10-20）

修复当前新卡面模板中的插画错位，保留已有卡框、工坊入口和后端数据流程。没有修改对局绘制组件、桥接层或引擎代码，没有重新导出发布 EXE。

## 原因与处理

- 卡框和插画 TextureRect 使用默认最小尺寸，原图尺寸会撑大缩小后的控件。改为忽略纹理最小尺寸，卡框、插画槽与文字统一按 500×701 设计坐标换算，并保持长宽比。
- 编辑页没有经 TextureCache 读取 diyart://，导入图及单卡缩放未进入实际预览。已接入与卡库一致的纹理、缩放来源。
- 素材库保存的是完整卡面。合成时仅取内部插画，剔除旧标题、费用和底部徽章；已经裁切的导入图不重复裁切。
- 单位和指令共用了单位坐标。核对原始 Astral PSD 后，分开顶部插画、卡名和规则位置；指令卡的卡名底图占位不再遮挡动态标题。
- 原微调工具初次没有同步绿框，按固定缩放重复换算鼠标位移，且滚轮值会被旧输入框覆盖。现按显示尺寸同步槽位与控件，从输入事件坐标统一换算到模板坐标。
- 微调使用独立画布，避免被编辑器 VBox 重新布局；未保存的修改仅作用于弹层，关闭丢弃，保存后立即刷新预览。
- 模板保存为 version 2，分别记录 unit/order。兼容旧版单组坐标为单位模板，并拒绝无效尺寸与缩放；单张卡牌的 ArtScale 保持独立。
