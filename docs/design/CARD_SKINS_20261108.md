# 工坊异画与数值定位

入口：DIY 工坊 → 打开卡包 → 打开卡牌 → 卡图 →「异画与数值位置…」。

异画是工坊卡牌的展示设置，**只支持导入完整卡面**：包含卡框、卡名、插画和规则文字的整张图片，不提供插画/卡框分层编辑。图片格式、像素尺寸、宽高比和文件体积均不受限制，原图字节原样保存（不缩放、不重编码、不裁剪）。图片整张铺满卡牌控件显示，不重新拼装卡框，也不叠加卡名或规则文字；因此不受原版卡框模板限制。

## 使用

1. 导入完整卡面（任意引擎可读的图片格式、任意尺寸／比例／体积）。原图字节原样复制进卡牌的受管理目录，不依赖导入源文件；Android 文档（`content://`）同样按原始字节读取。文件选择器不再过滤扩展名。
2. 单位卡逐项设置部署费用、攻击、防御／剩余生命、行动费用；指令和反制只设置部署费用。
3. 拖动预览中的数值框调整位置，或输入 X/Y/宽/高百分比。
4. 设置数字颜色和覆盖底色。底色用于遮住图片上印好的原数值。
5. 点击「保存异画设置」，再按工坊的正常保存流程生效：普通 DIY 卡保存卡牌；原生卡包保存卡包草稿后应用修改。
6. 「移除异画，恢复默认卡面」只移除异画设置，原始导入文件不受影响。

## 保存与分享

- `DiyCardDraft.AlternateArt` 保存兼容卡牌的完整卡面文件与四个数值区域，图片保存在卡库的 `art/` 目录，文件名为 `alt-<SHA256>.<原扩展名>`（按内容哈希去重，保留原始扩展名与字节）。
- 原生卡包的 `workshop.presentation.json` 在卡牌条目中保存 `alternateArt`；图片保存在包内 `art/alt-<SHA256>.<原扩展名>`。
- 原生卡包导出和兼容卡包转换导出都会携带完整卡面与数值位置，导入后可继续编辑。
- 异画属于卡牌，不属于卡组外观，也不使用外观装备或房间外观同步通道。
- 收藏、构筑、手牌、查看和场上卡片读取同一份卡牌展示设置。当前卡包的异画对同 CardId 的卡片生效，不按所属玩家或卡组区分。
- 动态数值只读取引擎视图；隐藏卡牌仍显示背面。异画不修改 CardId、效果和规则定义。
- 原生卡包中无法读取的异画元数据、或异画图片路径缺失时，回退默认卡面。
- 仅保留两类非创作限制：卡面文件引用不得包含路径逃逸（`Checked()` 只校验相对文件名与安全的扩展名字符），四个数值区域仍须落在 0–1 的归一化卡面内。外观装扮那套 2 MiB／1024px／PNG 归一化不作用于异画。

## 数值对齐（不变）

- 四个区域仍是 `SkinRect` 归一化坐标（X/Y/宽/高均按卡面百分比），拖动、输入、数字颜色与覆盖底色、实时数值读取逻辑均未改动。
- 任意宽高比的完整卡面都会整张铺满卡牌矩形（拉伸显示），数值框仍按同一套百分比对齐；编辑预览与收藏／手牌／场上的基准一致。

## 验证

- `CardSkinTests`：兼容卡牌重启恢复、非法位置和路径拒绝、原生卡包草稿与导出导入保持图片及位置、旧卡库兼容、规则定义不变，以及任意体积／任意扩展名完整卡面字节原样保持。
- `--verify-card-skins`：工坊真实入口、完整卡面导入、数值坐标与拖动、保存草稿、应用修改、卡包导出、收藏/手牌/场上绘制和隐藏卡牌。
- 验证截图位于运行副本 `artifacts/card-skins-workshop/`。
