## 攻击、受击与退场

对战页使用独立 `BattleCombat` 表现层：瞄准 → 发射与弹道 → 命中与伤害盾 → 按投影反击 → 死亡与残留 → 消费最终布局。原有动画画廊保留为旧版 QA 工具，本阶段的棋盘演出不依赖其简单图元爆炸。

| 默认兵种 | 发射与飞行表现 |
|---|---|
| 步兵 | 短枪口闪光、三发连续曳光弹、轻微后坐 |
| 坦克 | 较强炮口闪光、单发炮弹、卡面后坐 |
| 火炮 | 发射闪光与抛物线炮弹 |
| 战斗机、太空战机 | 浮空前掠、连续机炮弹道，射击期间轻微起伏与侧倾 |
| 轰炸机 | 浮空前掠和目标上方落弹，保持连续飞行姿态 |
| 太空战舰 | 原位炮击后坐（18 单位位移）、炮口闪光与炮弹，不浮空 |

空军和太空战机用 0.45 秒缓入缓出抬升，起飞前移 20、额外抬升 12；射击和反击受击期间持续前掠、轻微起伏与侧倾。前掠及姿态淡入淡出使用平滑缓动，枪口位置跟随卡面。最后一次命中后继续飞行 0.25 秒，再用 0.35 秒落回，同时收住起伏与侧倾。落回与既有烟尘收尾重叠。三个时长集中在 `BattleCombat` 的常量中，等待、缩放及收尾自动同步。太空战舰不浮空。减弱动效跳过浮空，中断会清除全部飞行偏移。这些均为 UI 表现参数。

命中使用火光、灰褐烟尘和碎屑的独立纹理层，伤害盾在其上方保持可读；存活卡消费适配器给出的新血量。地面步兵退场以烟尘为主，飞机和装甲单位使用更持久的火球。死亡卡隐藏后，效果继续留在原位置；最终队列重新排布。总部摧毁使用更大烟火与碎屑，结束标题直接消费 `ResultTitle`。未提供结果标题时只显示“对局结束”。

音效复用本地既有 mp3，并按兵种选择。未将这些声音声称为原版音轨。减弱动效减少位移、碎屑和扩散，保留结果、时序与音效设置。

## 与引擎的边界

`BattleDemoAdapter` 是可替换的本地动画场景夹具，包含少量示例数据转换，**不是生产规则实现**。齿轮中的攻击及 HQ 演示仅在本地演示模式可用；外部投影下禁用这些场景复位入口。

正式接入仍是候选契约，尚未要求主引擎采用或修改架构：

```csharp
// 外部适配器投影允许动作和可见状态；UI 不执行这些动作的规则。
main.ApplyMatch(match, actions);
main.CommandRequested += command => adapter.Submit(command);

// 动作已由外部处理，传入历史角色值、结果与最终投影。
await main.PresentCombatAsync(resolution, afterActions);
```

`UiCombatResolution` 携带攻击前双方值对象、两侧伤害、攻击后双方值对象（空值表示已移除）以及 `After` 状态。UI 不从攻防推算伤害、不判定反击是否合法、不从 HQ 缺失推断胜利。隐藏角色不播放揭示其身份的演出。`UiSnapshots.Freeze` 在进入演出前复制嵌套集合，避免延迟读取活引用。

操作请求在外部模式下只通过 `CommandRequested` 发出。`AttacksEnabled` 默认关闭；提供允许动作后才开放。UI 不自行扣指挥点、扣血、移动或删除单位。生产引擎的关键词、卡牌规则、真实回合与事件队列仍未接入。

Esc/右键、切页和偏好变化可中断演出：若已收到解决结果，直接消费其 `After`；若新全量状态或演示复位覆盖当前演出，旧任务失效。清除临时效果与卡面位移，不回滚引擎结果。
