# 三档部署动画逐帧对照

参考：`H:/Working Folder/8月9日(1).mp4`，15.84 秒，3840×2160，30 fps。
用户确认原速、仅剪辑，并说明部署强度随身材（防御）增加，约 4、7 为分界。
本次分档采用防御 1–3 / 4–6 / 7+，只读取 `EffectiveDefense ?? BaseDefense`。

以下时间来自解码帧，而非旧实现的注释。帧号从 0 开始；一帧约 33 ms。
测量图片缩为 1920×1080，像素值均按该尺寸。单个样本只能支持该次演出，不能证明整个原版的所有单位都使用完全相同的参数。

## 本次修改

`BattleSequence.SlamStyle` 保存三档时序，真实对战、演示和录制共用它：

| 档位 | 放大阶段 | 峰值 | 蓄势后段 | 收牌 | 桌面震动 |
|---|---:|---:|---:|---:|---|
| 防御 1–3 | 无 | 1.00 | 无 | 0.267s | 无 |
| 防御 4–6 | 无 | 1.00 | 0.433s | 0.367s | 约 0.47s，较轻 |
| 防御 7+ | 0.500s | 1.18 | 0.267s，回收至约 1.14 | 0.067s | 约 1s，较重 |

- 记录实际松手的位置、尺寸、缩放及旋转，排队期间保留持牌位置，正式演出从该位置接手。
- 全程只保留一个可见卡牌实例；完整卡面与场上卡面由同一个代理切换，尘土退场后再交给稳定场上节点。
- 中、重单位的桌面位移带动所有卡牌；轻单位不震屏。去除单帧压扁及亮度闪烁。
- 尘雾约延迟 0.3s；重档增加细小橙色飞散颗粒。使用程序绘制的柔和尘雾，颜色/粒子密度为适配项目素材的近似，未提取原版特效纹理。
- 演示部署也经过正式演出队列；修正动画演示中秒/毫秒混用与 `t == 0` 分支无法执行的问题。
- `--capture-slam` 录制真实部署链路，包含整桌震动；删除原来单独重建压扁/闪光动作的录制实现。
