# A.22：菜单交互与收藏连续滚动

日期：2026-10-11。版本：`0.0.0-alpha.22`。

按用户要求收拢重复按钮，加入 splash、transition 和 hero section 对应的原生 Godot 交互，并移除收藏分页。

## 导航与按钮

- 顶部是唯一的全局导航：品牌返回指挥部，我的卡组、卡牌收藏、DIY 工坊，右侧帮助／设置。
- 移除侧栏、首页三个重复快捷入口、首页右侧开始／编辑按钮和全局“构筑”标签。首页保留一个橙色开局按钮，有效卡组直接开局；无有效卡组时改为选择卡组。
- 卡组库仅保留“＋ 新建卡组”封面入口，顶部保留导入。构筑由新建或所选卡组的编辑进入，编辑页移除重复的“我的卡组”返回按钮。
- “设为首页卡组”保存首页使用的卡组；“开始对战”使用当前查看卡组直接开局。两者保留不同语义，浏览封面仍不自动改变保存的选择。
- 有运行中对局时，顶部出现返回战场，继续原实例与待选状态。战场仍铺满窗口。

## 动效

| 场景 | 行为 |
|---|---|
| 启动 splash | 在整理收藏、检查卡组、布置界面、就绪四个真实阶段更新状态与进度；阶段工作前让出帧以绘制。没有人为加载停留计时 |
| splash 退场 | 就绪后 180 ms 淡出，此时解除覆盖层鼠标拦截；减弱动效时直接移除 |
| 页面 transition | 新页面立即接收输入，200 ms 淡入、220 ms 从下方 12 px 归位。新导航取消前一次过渡并恢复锚点与透明度，进入战场直接展示 |
| 首页 hero section | 460 ms 展开卡牌扇面并描绘地图路线；鼠标在区域内移动时，卡牌最大约 8 px 跟随。隐藏页面停止绘制变化 |
| 按钮反馈 | 140 ms 金色下划线展开，支持鼠标悬停和键盘焦点，不移动点击区域；动态生成按钮也接入 |
| 减弱动效 | 立即结束菜单位移与主视觉展开，关闭鼠标跟随；悬停反馈直接切换状态 |

所有动效使用本地 Godot 控件、Tween 和现有桌面／地图／卡背资产，无网页或视频运行依赖。

## 收藏

- 删除上一页／下一页和页码，滚轮或滚动条连续访问所有结果；右侧详情独立滚动。
- 全部结果保留为定义数据，滚动范围代表完整列表；仅创建可见行及前后各一行的卡牌节点。固定行高避免缩略图加载改变滚动位置。
- 改搜索／筛选会回到顶部，空结果清理旧缩略图。离开再返回保留滚动位置与选中详情；卡库更新会重建结果。
- 可用宽度改变时调整列数，并按原位置附近的卡牌换算滚动位置。活动窗口没有重复卡牌，测试覆盖全部 315 张及末张点击。
- 此处只改变浏览表现，卡组构筑的分页与原生规则继续沿用。
