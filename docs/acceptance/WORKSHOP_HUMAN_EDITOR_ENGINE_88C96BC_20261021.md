# 效果编辑交互修正与引擎更新

## 问题

用户实际截图中的“高级资产”直接把原生效果声明展开为表单，要求填写版本、触发器、包装器、注入等内部字段。这个入口没有解决制作任务的理解成本。“高级”命名不构成可用性设计。

## 本轮修改

- 删除该入口及其递归字段编辑器，改为“词条与效果”：显示作者提供的中文效果名称、说明、相关时机和编辑操作，不显示路径、内部编号和 JSON。
- 未提供单独说明时，可显示作者在原声明名称中填写的简短说明。不会分析 CSX 后猜测完整条件和行为。
- 原有脚本不能可靠还原时明确说明；修改名称与说明不改脚本。选择重新编排则明确说明替换影响，保存前备份完整卡包；取消不改原有效果。
- 新建、重新编排效果使用通用图形规则：发生时机、条件、目标、动作。一项独立效果不再显示多余的规则列表、复制和排序工具。日常入口没有原生模式／原始声明编辑工具。
- 图形规则编译和原生文件提交仍由桥接层完成，保留原效果身份。保存的共享效果可在卡牌规则页勾选使用，选择目标的计划随卡包规则声明读取。
- 国籍改为中文选择，自定义国家仍可创建；新卡牌、新效果、新卡包的内部 ID 自动生成。已知词条使用中文勾选，未知导入内容保留，不要求用户手写逗号分隔的标识。
- 主操作“转正并更新卡池”改为“应用修改”；日常工具栏移除版本／依赖原始声明入口。
- 修复嵌套弹窗所属窗口、滚动布局和保存按钮被挤出屏幕的问题；验证用鼠标输入坐标支持嵌套窗口和窗口缩放。

本轮没有改对局布局，没有开发联机，没有开启生产对局的沙盒授权。

## 引擎核对

引擎工作区从 `a35e0b9` 快进到 `88c96bc9f8ab3a8f8cc63c0cdb515d3df0df445f`，工作区干净，没有本地引擎源码修改。

新增内容主要包括无头沙盒、调试原语、MCP Bridge，以及反制效果装配。反制效果现在装配进 Counter handler 链，主触发器与其他触发器不再照旧挂载以避免双触发；反制 handler 使用 `CardTriggerView`，不匹配的条目会隔离。因此不能把任意已存在脚本的通用编辑、或普通部署效果改为反制卡，直接宣称为可用反制规则。

沙盒 API 是额外的引擎装配能力，本轮没有将它转换为普通编辑页面的底层控制面，也没有放宽正常对局规则。

目前只保证已验证的普通图形效果流程。任意 CSX 自动还原、所有反制作者规则、完整发布回归仍未完成。没有推送、打包或升级发行版本号。运行中的旧窗口需要保存后重新启动才能加载新程序集。
