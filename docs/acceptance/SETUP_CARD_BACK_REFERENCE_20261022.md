# 卡组选择按原版参考重做

日期：2026-10-22。此记录替代同日上一轮“卡牌插画缩略图＋地图列表”的视觉实现说明。

## 参考与具体修正

实际重新查看了已存档的官方卡组选择图 `artifacts/research/workshop-ui-20261021/kards-decks.png`，以及官方卡组自定义局部图 `kards-deck-panel.png`。来源：[KARDS 新 UI 说明](https://www.kards.com/news/new-user-interface)、[官方卡组自定义帮助](https://support.kards.com/hc/en-us/articles/27800786503961-Deck-Customization)。参考是历史官方素材，不声称已操作最新原版客户端。

上轮主体选错：任取一张卡的插画放在纸质列表项里，不能等同于原版的卡组选择。

本轮实现：

- 木桌中央最多三列竖向卡背，名称与国家标识置于下方暗色铭牌。
- 整张卡背可点击，选中有金框与旗签；不再在封面中嵌套“选择部队”按钮。
- 左侧集中选择作战模式；右侧集中当前卡组名称、同款放大卡背、编辑与出击。
- 训练、好友对战、卡组管理及工坊说明保留，房间列表留在好友模式中。
- 卡背是本项目绘制的配色、边饰、纹理磨损与简化图形。复用项目既有木桌素材，不裁剪官方截图当产品资产，也不声称包含原版全部卡背或自定义装饰功能。
- 卡组选择与右侧预览使用同一绘制控件；国家名优先读取现有国家目录，支持自定义国家图标，无图标时有统一图形后备。
- 好友空列表换成可折行提示，不因一行长提示把左栏撑宽。
