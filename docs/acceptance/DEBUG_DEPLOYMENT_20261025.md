# 图形化游戏调试台与部署选靶（2026-10-25）

接续 [部署指向交接](../planning/DEPLOY_TARGETING_HANDOFF_20261025.md)，保留已提交的解析器与跨段目标复用修复。

## 功能

- F1 / 反引号 / 右下角“控制台”打开面板，Esc 或关闭按钮收起。手机返回键优先关闭面板。
- “对局调试”页显示当前回合、阶段、双方资源、总部、牌库与手牌数量、等待的选择器及最近拒绝原因。
- 卡牌检查器显示实例 ID、印刷与实时属性、当前词条、行动限制、原生效果及触发钩子、属性修饰及期限。
- 本地对局显式启用调试后，可暂停/恢复对手自动行动、推进当前回合、取消选靶、给双方抽牌/增加资源、从本局卡池生成手牌/召唤单位，以及对选中目标造成伤害、回复、设置属性、沉默或消灭。
- 调试通过原生服务执行，与正常操作共用命令锁；选择器取消使用独立通道，能够取消正在等待的操作。退出调试恢复启用前的对手自动行动设置。
- 联机与回放显示只读投影，不暴露远端修改入口。可复制诊断快照；日志支持级别与内容筛选、复制和清空，内容中的 BBCode 按原文显示。

## 部署修复

单位牌的落点 `GapId` 与效果目标 `TargetUid` 独立保留。拖向目标时同时提交二者；拖到空位时只提交落点，由原生预打出选靶等待玩家选择。

指定落点与旧版槽位参数现在也经过 `BeginUnitPrePlayAsync`，不再绕过预打出；选中目标只消费目标意图，保留落点。取消发生在部署和扣费之前。

动态生成的卡在打出前补注册目标捕获。旧展示元数据若声明了原生效果中已经不存在的部署触发，不得凭空发起选靶（H39 的旧 `desktop-effects.json` 属于此类）。候选预览为纯查询，不再给所有候选发出“被指向”事件；仅最终选择产生通知。
