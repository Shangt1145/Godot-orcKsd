# Beta.4 工坊工作区更新记录

日期：2026-10-21。引擎基线：`a35e0b9076700a371043c8151c1f1df9edd45344`。

本轮是可操作的工坊更新，尚不是 Beta.4 发行验收。版本号保持 Beta.3，没有推送或生成新的发行包。引擎工作区保持干净；本轮没有重新设计对局布局，没有实现联机。

## 已落地

- 卡包内先浏览卡牌，再进入单卡制作。卡牌列表支持搜索与分页，每页最多 24 项；不能生成预览的源声明仍提供“待修复草稿”入口。
- 单卡制作分为属性、规则、卡图、描述四页，右侧固定大预览。属性采用归属／分类、费用／战斗属性双栏，源标识与完整声明进入高级查看。
- 单位、指令、反制自动切换既有 Astral 母版；原生反制写入 `countermeasure`。词条绑定真实 `attributes` 字段。
- 自定义国家提供中文名称创建入口，生成规范 ID，经引擎 `Faction.RegisterCustom` 登记；声明放在卡包呈现元数据中，随包导出和再次导入。构筑主国目录及名称显示合并正式包中的自定义国家。
- 属性修改只补丁对应的原生组件，不通过旧 DIY 草稿重建整张卡；未知字段保留。
- 图形规则复用现有通用 Inspector，编译由桥接层执行；编辑器自己的规则与导入包原有效果分别保留。选择计划写入 `desktop-effects.json`，重复保存替换自有规则，避免叠加。
- 保存源声明、sidecar 和呈现数据时保留回滚副本；卡图修改不再覆盖已有描述和规则编辑元数据。删除卡牌同步清理卡面文本和选择计划引用。
- 草稿保存与正式转正分开；离开未保存表单可保存、放弃表单修改或继续编辑。整个工坊的跨页面退出也经过此保护。
- 自带内容的作者引用使用用户目录工作副本，未扩大至发行目录的写入权限。损坏目录索引不会自动启用本机包；中断的新卡包草稿可以完整导出。
- `requires` 不再直接解释为扩展包归属，展示归属读取独立元数据和明确的自带扩展兼容表。

## 仍需完成的发布工作

### 同日修正：自带包仍进入旧界面

用户实际截图暴露了原生路由仅匹配 `Installed` 包的问题；自带“铜墙铁壁系列”从工坊首页进入时仍使用旧编辑器。已将修改选择页与直接 `OpenPack` 入口改为匹配全部已发现原生包。已有旧覆盖草稿的保护条件保留，未迁移或删除用户草稿。同时补上自带卡图在新版列表和大预览中的回退，以及原生小写稀有度的中文显示。

新增实际验证从首页依次点击“卡包 → 修改 → 铜墙铁壁系列 → 卡牌”，确认进入原生工作区，并另外检查直接打开自带 `builtin` 包。1600×900、1280×720 均通过；证据在 `artifacts/beta4-shipped-route-fix-20261021/`。程序运行时不会自动加载重新编译的程序集，需要保存后重启原有调试窗口。没有关闭用户窗口或修改其持久化草稿。

1. 清理并重跑全量单元与完整 UI 回归，确认新引擎下的失败来源。
2. 原生包名称、扩展归属和引用关系仍需完整的包级编辑面；当前四页工作区针对卡牌，旧工坊编辑路径保留。
3. 导入的任意 CSX／不透明原生效果仍保留原声明，不能声称已自动还原为可编排规则。`texts.json` 兼任编译输入时不能只修改显示文本。
4. 中断 `.tmp` 没有公共恢复 API；提供导出或备份，不伪装为自动续编。转正后激活失败的恢复流程仍需更完整的故障注入验收。
5. 原生卡图页已经接入插画／完整卡面导入和实时母版预览，但还没有合并旧编辑器的全部裁切、缩放、对齐操作。
6. 所有发布门槛完成后再推送、打包，并检查实际发行目录中的脚本运行依赖。不要直接把当前工作区作为正式 Beta.4 发布。
