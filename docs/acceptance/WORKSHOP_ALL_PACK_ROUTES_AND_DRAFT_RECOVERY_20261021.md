# 全卡包入口与草稿恢复修正（2026-10-21）

## 问题与结果

用户截图暴露了两处实际遗漏：打开“铜墙铁壁系列”时，持久化的 `.tmp` 草稿被当作错误交给用户自行删除；太空战争、自建包、机制示范包及扩展包仍走旧三栏页面。先前只完成原生卡包工作区，不代表所有入口完成。

现统一为“卡牌一览 → 点击卡牌 → 属性／规则／卡图／描述 + 大卡面预览”。旧卡包保留原有读写适配器、编号、效果和自定义词条，不进行有损格式迁移。旧编辑器的卡牌列表侧栏和重复标题被移除，属性分为归属分类与费用战斗属性两列；指令和反制隐藏单位专属字段。原有新建国家、卡图调整及规则编辑功能保留。

普通修改入口及卡包管理入口均涵盖已有本地覆盖的内置卡包。旧卡包规则编辑同样启用面向玩家的 Inspector；无法可靠转换的导入效果保持原样并明确说明。

## 草稿恢复

- 再次打开时自动恢复已保存草稿；切换卡包也保留各自的草稿。
- 通过引擎公开编辑 API 编辑恢复副本；先保留原稿完整备份。
- 恢复会话保存后更新持久化检查点，可再次重启继续。
- 点击“应用修改”前，正式卡包不受草稿变动影响；应用失败恢复原正式版本。
- “放弃未应用的修改”需确认，草稿移入备份；损坏清单也可通过此入口处理，无需用户操作文件目录。
- 用户原有铜墙铁壁 `.tmp` 的清单已只读检查，确认为有效的 `orc.bulwark` 草稿。没有手动删除、移动或修改原草稿。

本节替代之前验收文档中“中断草稿需手动处理／备份后重新开始”的限制说明。
