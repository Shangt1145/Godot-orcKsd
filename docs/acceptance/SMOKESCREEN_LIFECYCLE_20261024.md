# 烟幕的前线与攻击移除规则（2026-10-24）

按用户规则修复：位于前线的单位和主动攻击后的单位不能保留烟幕。烟幕与“隐蔽/covert”是两个独立词条，本次没有修改隐蔽机制。

## 实现

- 引擎统一移动落地点：单位成功进入前线后、发出位置变化前，移除烟幕；移动被取消或未落地时不移除。
- 单位化入口：直接部署/加入前线也移除烟幕。
- 词条统一授予口：前线单位不能重新获得烟幕，包括携带内容的授予入口。
- 攻击共用执行链：主动攻击时移除烟幕，并在攻击后效果处理完成后再次确保烟幕移除。普通指挥和效果攻击共用该路径；取消选靶不执行此步骤。
- 撤回支援线不会自动恢复已移除的烟幕。未将本次规则扩展为“曾经攻击过就永久禁止以后由新效果获得烟幕”。
- 烟幕移除通过真实运行时词条撤销，并发出关键词变化更新，原生与联机投影读取同一状态；不只隐藏图标。

## 验证

- 新增 3 项 SmokeScreenLifecycleTests，修复前 3 项均失败，修复后通过：推进前线/撤回、直接加入前线/禁止重新赋予、主动攻击/取消保留。
- 更新三项原先假设“前线保留烟幕”或“攻击后仍受烟幕保护”的旧测试。随机词条测试仍检查授予前后的真实组合和重甲伤害；老兵测试移至支援线，继续验证升级清除旧烟幕词条；攻击候选测试增加可到达的无烟幕对照。
- 引擎全量：1360/1360，通过日志 `artifacts/smoke-engine-final.log`。
- UI 全量（新增显示回归前）：570/570；新增远端关键词回归后专项 5/5，确认烟幕移除表现为 KeywordsChanged，且不产生虚构伤害。最终发行全量结果见 hotfix.3 记录。
